## 主体（按主题）

### 通用：Car Model 与 8 功能昵称体系

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
  - https://personalityhacker.com/blogs/podcasts/podcast-episode-0225-the-car-model-your-personality-cognitive-function-stack
- 证据：
  - Personality Hacker 把四功能栈解释成一辆车：dominant 是 `Driver`，auxiliary 是 `Copilot`，tertiary 是 `10-Year-Old`，inferior 是 `3-Year-Old`
  - `Driver` 被写成最自然、最常用、最容易默认接管人生的认知过程；`Copilot` 是帮助人格保持平衡的第二过程，长期成长的关键在于学会让它稳定上线
  - `10-Year-Old` 被解释成带来 playful energy 和 relief 的位置，像一个有天赋但不稳定的小孩；它既能提供创意与乐趣，也会在不成熟时让人格“卡在舒服区”
  - `3-Year-Old` 被描述为又脆弱又想证明自己、会在疲惫和压力下失控的位置；成熟成长的一大主题，就是学会照顾而不是羞辱这个部分
  - 站点还给 8 功能各自起了易记昵称：Ni = Perspectives，Ne = Exploration，Si = Memory，Se = Sensation，Ti = Accuracy，Te = Effectiveness，Fi = Authenticity，Fe = Harmony
  - `Car Model` 页同时说明：四字母类型的本质不是标签，而是这四个位置分别由哪四个功能坐进去；因此同字母但座位顺序不同，会导致截然不同的人格体验
  - 文章导航直接列出 16 个公开类型入口，说明该站确实为 16 型都建立了对应 `Owners Manual` / type pages 体系，即使并非每页都同样详尽
- 覆盖问题：A1, A5, A6, A7, B4, B12

### 通用：发展路径、loop、blind spot 与 shadow

- 来源 URL：
  - https://personalityhacker.com/blogs/podcasts/podcast-episode-0122-developing-your-10-year-old-tertiary-cognitive-function
  - https://personalityhacker.com/blogs/articles/is-my-3-year-old-inferior-cognitive-function-really-a-blind-spot
  - https://personalityhacker.com/blogs/articles/which-personality-shadow-functions-are-we-best-at
  - https://personalityhacker.com/blogs/articles/how-to-get-an-entj-out-of-a-personality-loop
- 证据：
  - 关于 `10-Year-Old`，站点强调它不是“没用的小孩”，而是有真实天赋但缺乏成熟监管的 relief process；如果 Driver 和 Copilot 长期疲惫，人会更容易退回这里寻找熟悉、快乐、低责任感的状态
  - `3-Year-Old` 那篇明确反对把 inferior 简化成“完全盲点”：它并非完全不可见，而是高度敏感、容易防御、很想被证明有能力，所以一被触发就容易表现得幼小又过火
  - 文章进一步说明：很多人误以为自己“根本没有 inferior”，其实更常见的情况是非常在意它，只是不知道如何稳定使用
  - `shadow functions` 一文把第 5-8 功能描述为在高压或失衡时更容易浮出的“背面能力”，并非全然邪恶；有些人甚至能在工作或人生后期把部分 shadow 用成特殊优势
  - `ENTJ loop` 文章提供了 Personality Hacker 对 loop 的核心定义：当人格绕过 Copilot，只让 Driver 和 10-Year-Old 互相强化时，就会出现 loop；这种状态看似高效或熟悉，实则越来越单一、越来越失衡
  - 以 ENTJ 为例，loop 表现为 Te 持续 push output、Se 追求即时行动和掌控感，而 Ni/Fi 没有被健康整合时，就可能显得过度外压、冲动、难以自省
  - 这个框架本身可迁移到所有类型：健康成长依赖 Driver + Copilot，失衡时更容易滑向 Driver + 10-Year-Old 的 loop，或被 3-Year-Old / shadow 触发
- 覆盖问题：A5, A7, A11, B8, B11

### 八功能页面证据

#### Ni（Perspectives）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-introverted-intuition-perspectives
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Personality Hacker 把 Ni 命名为 `Perspectives`，强调它会把表层事实拉开距离，去看 underlying pattern、future trajectory 和意义框架
  - 这篇文章把 Ni 写成一种“从更高视角看全局”的能力，擅长综合碎片并给出方向感
  - 与 Ne 相比，这里更突出 Ni 的收束、洞察、抽象整合与长期时间轴
- 覆盖问题：A1, A2, A3, A4, B3

#### Ne（Exploration）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-extraverted-intuition-personality-hacker
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Ne 被命名为 `Exploration`，重点不是抽象本身，而是对 possibilities、alternatives、idea generation 的外向探索冲动
  - 站点写它像一股不断往外探路的能量，会把一个点子迅速展开成多种路径和关联
  - 这一定义直接支持 B9：Ne 高的人在对话里更容易边聊边发散、边互动边长出新想法
- 覆盖问题：A1, A2, A3, A4, A8, A9, B3, B9

#### Si（Memory）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-memory-introverted-sensing-for-personal-growth
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Si 被命名为 `Memory`，不只是死记事实，而是依靠累积经验、身体记忆和熟悉参照来建立稳定感与可持续性
  - 文章明显把 Si 的价值放在 continuity、reliability、pattern from past experience，而不是刻板印象里的“守旧”
  - 这让 Si/Ne 的对照更清晰：Si 先问“以前什么有效”，Ne 先问“还可能怎样”
- 覆盖问题：A1, A2, A3, A4, B3

#### Se（Sensation）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-extraverted-sensing
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Se 被命名为 `Sensation`，强调直接进入现实、信任感官、及时响应眼前世界
  - 文章把 Se 写成对 risk、movement、urgency、physical reality 的天然同步，能把事情从“还在想”拉回“立刻做”
  - 与 Ni 对照时，Se 更偏现场、具体和行动；Ni 更偏图景、趋势和意义
- 覆盖问题：A1, A2, A3, A4, A8, B3

#### Ti（Accuracy）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/accuracy-as-a-decision-maker
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Ti 被命名为 `Accuracy`，文章核心问题就是：`Does this make sense?`
  - Personality Hacker 对 Ti 的抓手不是“逻辑很强”这类空词，而是内部一致性、定义精准、系统是否真正讲得通
  - 这让 Ti/Te 的区分非常明确：Ti 先追求 conceptually correct，Te 先追求 externally effective
- 覆盖问题：A1, A2, A3, A4, B4

#### Te（Effectiveness）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-extraverted-thinking-personality-hacker
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Te 被命名为 `Effectiveness`，强调 external results、structure、systems、execution 和 impact
  - 文章把 Te 写成“让事情真正发生”的能力：组织资源、排优先级、把判断落成可衡量输出
  - 这篇对 A8/A9 也有帮助，因为它暗示 Te 高的人在群体里更可能直接拍板、推进和定节奏
- 覆盖问题：A1, A2, A3, A4, A8, A9, B4, B5

#### Fi（Authenticity）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-introverted-feeling-fi-personality-hacker
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Fi 被命名为 `Authenticity`，核心是对个人真实、内在价值、self-congruence 的坚持
  - 文章把 Fi 写成会不断问“这是不是我真正相信的”“这是否忠于我”，因此它对虚假和自我背叛高度敏感
  - 与 Fe 的对照更像：Fi 更先检查 self alignment，Fe 更先检查 relational harmony
- 覆盖问题：A1, A2, A3, A4, A8, A9, B4, B9

#### Fe（Harmony）

- 来源 URL：
  - https://personalityhacker.com/blogs/articles/why-the-world-needs-extraverted-feeling
  - https://personalityhacker.com/blogs/articles/personality-development-tools-the-car-diagram
- 证据：
  - Fe 被命名为 `Harmony`，文章重点放在调节关系氛围、促进理解、让群体更容易合作
  - Personality Hacker 这里的 Fe 不是“讨好”，而是主动维护共识、情感气候和社会润滑
  - 这对 B5/B9 很有价值：Fe 高的人在圆桌里更容易担任润滑者、调停者、连接者
- 覆盖问题：A1, A2, A3, A4, A8, A9, B4, B5, B9

### 公开类型页样本

#### INTJ

- 来源 URL：
  - https://personalityhacker.com/pages/intj-personality-type
- 功能栈（按站点术语）：
  - Driver: Perspectives (Ni) / Copilot: Effectiveness (Te) / 10-Year-Old: Authenticity (Fi) / 3-Year-Old: Sensation (Se)
- 证据：
  - 页面把 INTJ 写成有远见、擅长策略、偏好独立思考与系统掌控的人
  - 其核心驱动力明显是理解复杂系统并把愿景转化为现实结构，这与 Ni-Te 的组合完全一致
  - 人设层面更像“先独立想透，再出手定盘”的 architect / strategist

## 交叉验证提示

- Personality Hacker 对 8 功能的命名方式非常有特色：`Perspectives / Exploration / Memory / Sensation / Accuracy / Effectiveness / Authenticity / Harmony`。后续整理功能文件时，应把这些视为“PH 的教学别名”，而不是替代标准术语本身。
- 该站特别强调 `Car Model`、`loop`、`3-Year-Old`、`10-Year-Old` 这些成长隐喻，适合用来补 A5/A11，但如果和更学术站点冲突，需要注明“PH 偏教练化、成长实践化表达”。
- 站点明显偏“人格成长工具”和“自我发展框架”，比 cognitiveprocesses / personalityjunkie 更口语，也更容易直接迁移到 prompt 设计中的角色气质描述。

## 失败/盲区记录

- 本站没有抓到可直接复用的 typed dialogue / quote-style examples，因此 A10、B10 仍需其他站点补。
- 虽然站点存在 16 型类型页体系，但本轮更适合按主题结构抓 `Car Model + function nicknames + growth model`；公开类型页只抽取了部分样本来补 B 类问题，不适合把本站单独当作 16 型完整人格库。
- Ti / Fe / Te / Fi 的文章中，`Accuracy / Harmony / Effectiveness / Authenticity` 这种教学命名很强，后续整合时要注意不要把昵称误当正式功能定义原文。
