## 主体（按主题）

### 站点范围：测试工具站而不是人格百科站

- 来源 URL：
  - https://sakinorva.net/
  - https://sakinorva.net/functions
  - https://sakinorva.net/test/function_bunya
- 证据：
  - `sakinorva` 的公开 MBTI/荣格相关资产核心是测试，而不是 16 型逐页百科或 8 功能逐页百科
  - 当前至少能确认两套核心测试：旧版 `Cognitive Function Test (Grant/Brownsword, Myers)`，以及新版 `Sakinorva Cognitive Function Domain Test`
  - 新版 domain test 页明确写明它有 `256` 题，并且结果会把原始功能分数按多种算法“塞回”不同类型，同时还给出一个 `non-pigeonholed type`
  - 旧版 functions 页从搜索摘要可见是一套 `96` 题的认知功能测试，结果会用 `4` 种不同方法计算；这说明 `sakinorva` 从一开始就把“同一份答题可以被不同类型理论解释”作为设计重点
- 覆盖问题：A1, A5, A7, B4, B12

### 测试立场：网站如何看待“认知功能”

- 来源 URL：
  - https://sakinorva.net/test/function_bunya
  - https://sakinorva.net/library/kensasiryou/bunyabetu/question_time
- 证据：
  - 新版 domain test 开宗明义地写：`this website will forever maintain the position that there is no such thing as the cognitive functions`
  - 但站点并不是完全抛弃功能话语，而是承认 typology 圈子里的人确实会用“认知功能”来理解自己，所以它希望把这些互相混杂的功能理解方式拆开、整理得更严谨
  - 站点的核心姿态不是“我来告诉你真正的功能定义”，而是“不同人嘴里的功能其实在说不同东西，因此要拆成不同 domains 再测”
  - `Question time` 里作者也反复提醒：大家嘴里说的“accurate”往往并不清楚在指什么；在一个本来就充满 `magic` 的体系里，测试只能尽量减少神秘化，而不是保证绝对正确
- 覆盖问题：A1, A4, B3, B12

### 四域模型：latent / active / aptitudinal / valuing

- 来源 URL：
  - https://sakinorva.net/test/function_bunya
- 证据：
  - 新版 test 的最大创新是把每个功能拆成四个 domains 来测，而不是默认一个 `Ni` 或 `Te` 只有一种固定含义
  - 前两域被称为 `pure domains`：
    - `latent domain` 关注 mental activity 和 mental preferences，也就是内在思维习惯、倾向和脑内处理方式
    - `active domain` 关注 interaction with the world around you，也就是表达、沟通、调解、与世界打交道的方式
  - 后两域被称为 `materialized domains`：
    - `aptitudinal domain` 关注 skills，把功能和“你擅长做什么”联系起来
    - `valuing domain` 关注 values and opinions，把功能和“你重视什么、认同什么”联系起来
  - 页面还特别提醒：不要把 `latent = 内倾功能`、`active = 外倾功能` 机械等同；两者有重叠，但并不是这样简单一一对应
  - 站点承认 `aptitudinal` 和 `valuing` 会被某些“功能纯粹派”嫌弃，因为这些其实已经掺入人格、价值观、技能与社会表现，但作者认为现实中的功能描述本来就经常把这些东西混在一起
- 覆盖问题：A1, A4, A7, B3, B4, B12

### 题目风格：测试如何把功能翻译成行为线索

- 来源 URL：
  - https://sakinorva.net/functions
  - https://sakinorva.net/test/function_bunya
  - https://sakinorva.net/library/kensasiryou/bunyabetu/question_time
- 证据：
  - `sakinorva` 的价值很大一部分不在于理论说明，而在于它把功能差异翻成了大量可回答的行为与倾向陈述
  - 旧版 functions 页的题目风格明显偏传统 typology 语汇，例如：
    - `Ne` 会被写成“把世界看成等待探索的 possibilities”“是 brainstormer”“容易跑题”“容易开很多项目但收尾少”
    - `Ni` 会被写成“对未来有会成真的 hunches”“经常 just know things 却讲不清怎么知道”“在细节海洋里看到 big picture”
    - `Si` 会被写成“依赖 past experiences”“重视 details 和 routine”“不喜欢 change”“被认为 stuck in your ways”
    - `Se` 会被写成“活在 here and now”“risk-taker”“thrives on new experiences”“aware of surroundings”
    - `Te` 会被写成“organized”“take control before situations get out of hand”“streamline systems for efficiency”“trust hard facts and data”
    - `Ti` 会被写成“build internal logical frameworks”“question anything”“prefer truth over winning”“work through problems by yourself”
    - `Fe` 会被写成“greatly value social harmony”“value inclusion”“communicate tactfully”“become upset when care goes unappreciated”
    - `Fi` 会被写成“strict internal moral code”“stay true to yourself”“fiercely individualistic”“become stubborn about personal beliefs”
  - 新版 domain test 的题目风格更“技术化”也更碎，混合了内在认知、外在行为、技能和价值判断，例如：
    - `Ti/Te` 会落在“过度挑小逻辑错”“能察觉 fallacies”“知道怎样让系统运转更好”“更在乎 process 还是 result”
    - `Ni/Ne` 会落在“会把 ideas 之间的联系看得很清楚”“long-term thinking”“经常 prophetic insights”“是否容易 drop old ideas once novelty wears off”
    - `Si/Se` 会落在“难以 improvising”“good sense of memory”“move with confidence physically”“immediately adapt to high-pressure situations”
    - `Fi/Fe` 会落在“self-aware and aware of flaws”“harbor grudges”“value people’s experiences as unique”“take care of people”“know how to navigate emotionally tense situations”
  - 这也意味着 `sakinorva` 对 `A3/B3/B4/B9` 很有帮助，因为它给了大量“如果一个功能高，你会更容易认同哪些句子”的素材
  - 但它的副作用也很明显：题目里混杂了行为、价值、能力和自我叙事，所以它并不是纯粹的功能定义源
  - `Question time` 里作者还专门解释：很多题目的模糊性是故意的；有些看起来像 opposite 的问法，其实只是用第二分句澄清第一分句，不是严格逻辑反义句
- 覆盖问题：A2, A3, A8, A9, B2, B3, B4, B8, B9, B11

### 多算法分型：为什么同一组分数会给出不同类型

- 来源 URL：
  - https://sakinorva.net/functions
  - https://sakinorva.net/test/function_bunya
- 证据：
  - 新版 domain test 明确写出：它会把同一组 raw results 用多种 algorithms 解释，而且 `no particular algorithm is recommended by this test`
  - 旧版 functions 页从公开摘要可见，至少用了 `Grant/Brownsword` 和 `Myers` 两种思路；新版则把这种“多理论并行”推得更彻底
  - 新版页底公开解释了多种结果算法：
    - `Grant/Brownsword algorithm`：最重 dominant / auxiliary，把 inferior 当作 underdeveloped，使用 `IEIE/EIEI` 交替栈
    - `axis-based function type`：按 `Ne/Si` 与 `Se/Ni` 两条轴线收窄类型，如果轴不清晰就可能失败，只给出部分字母
    - `Myers function type`：不用交替栈，而是看各功能如何支持四字母轴
    - `purist's formula`：只看 `latent + active` 两个 pure domains，忽略 materialized domains
    - `magician's choice`：更照顾低 magic level 的结果
    - `strawberry formula`：更偏行为导向，也是顶部 function diagram 的基础
  - 页面还写到：如果你的前两功能以某种特定方式同时很负面，结果里甚至可能出现 `loop and grip indicator`
  - 这套结果体系最大的意义在于提醒我们：`类型` 并不是从原始功能分数里自然长出来的唯一答案，而是特定理论前提下的解释产物
  - 这对 `B12` 尤其重要，因为它把“类型对比”从静态标签差异，变成“同一人为什么在不同 typology 假设下会被读成不同类型”
- 覆盖问题：A4, A5, A6, A7, A11, B4, B8, B12

### Magic Level：站点如何处理“不接地气”的作答

- 来源 URL：
  - https://sakinorva.net/test/function_bunya
  - https://sakinorva.net/library/kensasiryou/bunyabetu/question_time
- 证据：
  - 新版 test 引入了 `magic level`，用来表示你的作答有多 “magical”
  - 页面明确说：magic level 越高，结果越不可信；这不是奖励，而是对不现实、过于神秘化或过于 typology-aware 作答的一种惩罚
  - 作者甚至直接吐槽：最需要担心 magic level 的，往往不是初学者，而是那些每月都来做一次 `Grant/Brownsword` 测试的老圈内人
  - `Question time` 里作者承认这个机制可能带有 neurotypical bias，因此后来对一些把“unusual behavior”一律当魔法的惩罚做了调整，改成更重罚 `logically unsound` 的作答
  - 同一问答页还说明：很多人做到中间大量选中间项、觉得题目含混、甚至“第五次尝试才过关”，其实都部分符合这套测试原本想制造的不确定感
- 覆盖问题：A1, B3, B8

## 交叉验证提示

- `sakinorva` 不适合当上游功能定义权威源，但非常适合作为“圈内测试如何把功能翻译成题面”和“同一功能分数如何被不同理论解读”的来源。
- 它和 `jungus` 都属于测试工具站，但两者风格很不一样：`jungus` 更偏中文产品化表达，`sakinorva` 更偏 typology hobbyist 内部话语和多算法实验。
- 后续如果 persona 文件里要写“这个类型为什么老和邻近型搞混”，`sakinorva` 的多算法和 axis-based 思路会很有帮助。
- 如果后续需要更纯的 A1-A4 功能定义，应优先回到 `totypes / typeinmind / personalityjunkie / personalityhacker`，不要把 `sakinorva` 的测题措辞直接当成理论定义。

## 失败/盲区记录

- 旧版 `https://sakinorva.net/functions` 当前直接打开会遇到 bot verification，本轮关于旧版测试的信息主要来自搜索摘要和被新版页引用到的说明，因此状态记为 `⚠️ 部分成功`。
- 本轮没有抓到公开的 16 型独立说明页，也没有抓到结果页样本，因此 `B1/B5/B6/B10` 等覆盖很弱。
- 新版 domain test 是一套 256 题长测，本轮只抽取了题面样本与页底结果说明，没有逐题做功能归类表。
- 本站没有可直接复用的真实对话例句，因此 A10、B10 仍需其他站点补。
