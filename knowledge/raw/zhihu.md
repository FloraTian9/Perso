  - 过度使用 `Se` 且分化不足时，阴影 `Ne` 会放大风险偏好，出现“可能行 = 现实也行”的夸大、赌徒感和扭曲创业冲动。

  - Dominant: Se / Auxiliary: Fi / Tertiary: Te / Inferior: Ni

- 证据：
  - 页面把 `ESFP` 的核心写成“对现实世界的高度信任与投入”，不是简单“爱玩”，而是先通过参与当下确认世界是真的。
  - 与 `ESTP` 相比，`ESFP` 的重点不是操作局势，而是让现实参与与个人价值、情绪张力和真实感觉保持一致。
  - `Se` 使其对场域气口、环境变化、他人反应和氛围流动极敏锐，因此常成为群体中的点火器或稳定器。
  - `Fi` 使其更容易以“我到底被没被打动、我是不是还在忠于自己”的方式理解现实，而不是先以结构和门道入手。
  - 页面特别强调其在创作、演艺或表达类位置时，优势更容易完整释放，因为此时现实体验和个人情感可以直接转化为成果。
  - 劣势 `Ni` 在高压和停滞状态下会突然显现为悲观预言、命运感或个人英雄主义式冲动介入，比 `ESTP` 更容易一腔热血冲上去。
  - 如果 `Se` 失衡且阴影 `Ne` 被放大，也会出现夸张风险偏好、迷信化解读和对自己现实掌控力的高估。
  - 页面把项羽式“正面冲阵、不肯彻底避战”的倾向，作为 `ESFP` 在高压权力场中的极端原型之一。

- 证据：

  - 页面直接写到他们在人群中常表现为滔滔不绝、辩论、输出观点，同时也会根据需要引导或扰乱他人情绪。

  - `Fi-Se` 让他们通过当下感官体验、美感、氛围与身体感觉去确认“我是不是真的喜欢/认同”，而不是先在可能性里反复推演。
  - 页面专门反驳“情感型更情绪化”的常见偏见，认为健康 `ISFP` 反而往往更能察觉和管理自身情绪与情感。
  - 第三 `Ni` 正常时能把现实体验沉淀成一针见血的洞见和具有触感的隐喻表达，因此在文学、艺术、设计等领域很有穿透力。
  - 不健康时，`Ni` 会演变成宿命式、自虐式预设，再加上 `Si` 和 `Ne` 阴影参与，变成越想越抽象、越排查越痛苦的螺旋内耗。
  - 页面把 `ISFP` 的核心目标写成“在真实生活中活出与自身价值一致的状态”，不是系统性改造世界，而是让现实和内在价值对齐。
  - 劣势 `Te` 在高度规划、目标导向和逻辑至上的环境里很容易引发压力、拖延、逃避；极端状态下甚至会反冲成冷硬、不择手段和报复性策划。
  - 健康 `ISFP` 的优势则被写得很具体：价值判断稳定、擅长把抽象情感翻译成具象表达、关系中忠诚私密、在低干预环境中有极强创造潜力。
- 覆盖问题：A2, A3, A5, A7, A11, B1, B2, B3, B4, B6, B8, B9, B11, B12

### INFP

- 来源 URL：
  - https://zhuanlan.zhihu.com/p/369530997
- 功能栈（若原站直接给出）：
  - Dominant: Fi / Auxiliary: Ne / Tertiary: Si / Inferior: Te
  - Shadow: Fe / Ni / Se / Ti
- 证据：
  - 页面把 `INFP` 写成典型 `Fi` 主导类型：情感强烈但很难表达，常心口不一，甚至显得漠不关心，因此经常招致误解。
  - `Fi-Ne` 让他们擅长从个人角度共情、在他人内心看见多样化的正确性和价值，也容易围绕个人情感与信念搭建理想世界。
  - 文中明确写到 `INFP` 想通过保护并强化内在信念去推动外界变得更理想，但也常因忽略客观事实和现实条件而失败。
  - 相较“思维反馈”，他们更重视情感上的反馈与接纳，也更在乎脑海里各种可能性想象是否真正打动自己。
  - 在协调关系时，`INFP` 容易陷入两难：到底是按自己的感受来，还是先为他人的情感与氛围服务，这对应其对 `Fe` 的矛盾体验。
  - 页面写到他们容易过度关注内部视角、忽略客观因素和外界环境变化，因此常带心不在焉、过于发散、抽离的观感。
  - `Ti` 阴影与过度思考结合时，`INFP` 很容易开始解构自己的情感认同，或用情感过滤逻辑信息，因此误测成 `INTP` 或 `INTJ` 的概率较高。
  - 与 `INFJ` 的区别被写成：`INFP` 往往更沉默、更热烈，也更容易在关系里缺乏稳定边界，而不是像 `INFJ` 那样自然维持距离。
  - 页面给出的强项包括深度共情、真诚执着、通过理念感染他人、在咨询或理想建构方面有优势；弱项则围绕现实落地与客观整合。
- 覆盖问题：A2, A3, A5, A7, A11, B1, B2, B3, B4, B6, B8, B9, B11, B12
