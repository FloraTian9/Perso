### 通用页证据

#### 通用：站点定位与方法论

- 来源 URL：
  - https://personality-type.com/
  - https://personality-type.com/category/mbti-cognitive-functions
  - https://personality-type.com/16-personalities
- 证据：
  - 站点把自己定位为 `MBTI + Socionics + Jungian psychology` 的混合型教育站点，强调 `cognition-first lens`，明确反对只背四字母或只看表层性格描述。
  - 首页和总览页一再强调：真正值得观察的是 `functions / stack position / blind spots / stress behavior`，而不是“你像不像某个 stereotype”。
  - 站点语言风格明显带作者立场，尤其偏好：
    - `hero / parent / child / inferior` 的 Beebe 式命名；
    - `quadra` 分组；
    - `visual typing`；
    - `compatibility` 与“对位互补”框架。
  - 因此本站既是高信息密度来源，也是高主观解释来源；后续抽取时更适合拿来补 `行为画像、栈位气质、盲点与失衡表现`，不宜把每个价值判断都当作中性定义。
- 覆盖问题：A1, A5, B1, B12

#### 通用：8 功能总览与站点定义

- 来源 URL：
  - https://personality-type.com/cognitive-functions-of-mbti
  - https://personality-type.com/16-personalities
  - https://personality-type.com/category/mbti-cognitive-functions
  - https://personality-type.com/introverted-intuition-ni
  - https://personality-type.com/extroverted-intuition-ne
  - https://personality-type.com/introverted-thinking-ti
  - https://personality-type.com/extroverted-thinking-te
  - https://personality-type.com/introverted-feeling-fi
  - https://personality-type.com/extroverted-feeling-fe
  - https://personality-type.com/introverted-sensing-si
  - https://personality-type.com/extroverted-sensing-se
- 证据：
  - 站点把 8 功能拆成 `perceiving` 与 `judging` 两大类，并持续强调“每个功能都和其对轴功能绑在一起”。
  - `Ni` 被写成未来导向、意志、专注、个人愿景和“知道自己想要什么”；它的阴影是过度未来化、忽视现实细节、可能变得阴谋化或强行让现实配合自己的意图。
  - `Ne` 被写成可能性、原型/梗/集体无意识、脑内同时保有多条路径；优点是创造性和预警能力，代价是更难收束选择与定方向。
  - `Si` 被写成记忆、舒适、纪律、稳定、忠诚、传统与耐力；它偏个人经验和过去的感官记录。
  - `Se` 被写成当下、行动、物理世界、表演感、反应速度和真实体验；它更关心“现在能做什么”与“别人此刻接收到什么”。
  - `Ti` 被写成追求逻辑准确与内部自洽，擅长把命题拆成真/假结构；它偏深度、原创推理和真值判断。
  - `Te` 被写成依赖共识、统计、best practice 与系统效率；它偏速度、可执行性、广度和结果。
  - `Fi` 被写成个人道德、边界、自我价值、真实性与“按自己认定的对错而活”；站点把它与艺术表达、身份感、私密原则紧密绑定。
  - `Fe` 被写成群体伦理、同理心、社交润滑、读氛围、让大家都舒服；站点非常强调它和趋势、礼貌、社交熟练度、照顾群体体验的关系。
  - `16-personalities` 总览页进一步把类型理解成 `8 facets` 的组合，而不是四字母标签；作者认为这比传统 dichotomy 更能解释“人为什么会这样反应”。
- 覆盖问题：A1, A2, A3, A4, A5, A6, B3, B4

#### 通用：16 型总览与四象限组织方式

- 来源 URL：
  - https://personality-type.com/16-personalities
  - https://personality-type.com/which-personality-types-are-compatible
- 证据：
  - 站点按 `Alpha / Beta / Gamma / Delta` 四个 quadra 组织 16 型，核心原则是：同 quadra 的 4 型共享同一组功能，只是顺序不同。
  - quadra 分组如下：
    - `Alpha`：INTP / ENTP / ISFJ / ESFJ
    - `Beta`：INFJ / ENFJ / ISTP / ESTP
    - `Gamma`：INTJ / ENTJ / ISFP / ESFP
    - `Delta`：INFP / ENFP / ISTJ / ESTJ
  - `16-personalities` 页给每型都配了 1 组极简画像，适合做“一句话人设”和快速区分。
  - 这些短画像反复把每型写成某种“认知脚本”：
    - INTP 是深度分析、舒适优先但底层很 caring。
    - ENTP 是连接万物、会辩、其实想与人相处好。
    - ISFJ 是高耐力、低调、情绪识别强。
    - ESFJ 是高社交、高照顾、对群体氛围极敏感。
    - INTJ 是封闭、长期规划、追求成为更好的自己。
    - ENTJ 是系统化推进、快速执行、情绪是软肋。
    - ISFP 是自我表达、审美、目标一旦锁定就很执拗。
    - ESFP 是热闹、现场感、会保护自己和别人的感受。
    - INFP 是高敏感、高价值感、难选但内心有方向感。
    - ENFP 是混沌创意、会共情、背着沉重过去继续往前。
    - ISTJ 是 duty、传统、耐久和“修东西”的稳定力量。
    - ESTJ 是效率、业务、抗压、传统价值。
    - INFJ 是安静但有使命感、重 empathy、外冷内烈。
    - ENFJ 是高社交、高表演感、爱趋势也爱带人。
    - ISTP 是理工脑 + 身体实践，既独处又渴望联结。
    - ESTP 是现场王者、讲义气、后期才慢慢长出方向感。
- 覆盖问题：A3, A5, A6, B1, B2, B12

#### 通用：兼容性、quadra 与对外互动框架

- 来源 URL：
  - https://personality-type.com/which-personality-types-are-compatible
- 证据：
  - 站点把 `同 quadra` 解释为 `camaraderie`：功能相同但排序不同，能互相学习，却不一定最省摩擦。
  - 它把 `对立 quadra` 解释为更高兼容性：因为双方拥有彼此的“相反功能”，更容易形成互补。
  - 这一套框架最适合后续抽 `B6 跨类型互动` 与 `B12 类型对比`，尤其能说明作者为什么经常把类型放到 quadra 内部和对立 quadra 一起讲。
  - 但该站的 compatibility 写法明显比官方 MBTI 更强结论化，应作为“本站立场”记录，而非最终产品中的硬性配对规则。
- 覆盖问题：A7, A8, B6, B12

#### 通用：对立功能与相邻类型对比页

- 来源 URL：
  - https://personality-type.com/intp-vs-intj
  - https://personality-type.com/infj-vs-infp
- 证据：
  - `INTP vs INTJ` 对比页把区分重点放在：
    - `Ti vs Te`：一个追求逻辑准确与自建结构，一个更依赖统计、权威与 best practice；
    - `Ne vs Ni`：一个持续展开多可能性，一个更像锁定愿景与目标；
    - `Si vs Se`：一个舒适、记忆、惯性更强，一个更在意当下表现与外界体验；
    - `Fe vs Fi`：INTP 更外显地关心他人反应，INTJ 更私有化地坚持自身价值。
  - `INFJ vs INFP` 对比页把区分重点放在：
    - `Ni vs Ne`：INFJ 更像单线愿景与使命驱动，INFP 更像多路并行与可能性警报；
    - `Fe vs Fi`：INFJ 优先群体伦理与他人感受，INFP 优先真实自我与个人价值；
    - `Ti vs Te`：INFJ 更偏自己拆逻辑，INFP 更容易在现实决策中动用外部效率与可行性。
  - 这两篇对比文说明本站很重视“别看字母像不像，而看功能是不是同一套”的区分法。
- 覆盖问题：A4, A9, A11, B4, B6, B11, B12

  - Dominant: Ni / Auxiliary: Te / Tertiary: Fi / Inferior: Se
- 证据：
  - 页面把 INTJ 写成 `strategist / closed-off planner`，强调他们常年活在自己的意义网络和长期规划里。

  - 弱点集中在完美主义、自我要求过高、挑剔与情绪疏离；Se inferior 则被写成既怕表现失误，又会在成长后追求更强现场掌控和形象呈现。

- 功能栈：
  - Dominant: Ne / Auxiliary: Ti / Tertiary: Fe / Inferior: Si

  - 页面反复强调他们虽然看起来爱杠，但 Fe child 让他们其实希望和人相处顺畅，也愿意在气氛合适时社交、安抚或逗乐别人。

  - https://personality-type.com/entj-personality-type
  - https://personality-type.com/16-personalities
- 功能栈：
  - Dominant: Te / Auxiliary: Ni / Tertiary: Se / Inferior: Fi

## 交叉验证提示

- 本站大量使用 `quadra / hero-parent-child-inferior / visual typing / compatibility tiers`，明显混合了 MBTI、Socionics 与作者自有解释框架。
- 类型页里有不少生动但偏主观的生活化写法，例如穿搭、长相、兴趣、社会角色和 meme 化标签；这类内容适合补 persona 氛围，不适合直接当严肃定义。
- 个别页面存在强结论性判断，例如谁最 compatible、谁更像什么气质、谁容易如何打扮；后续整合时应优先把它们归入“本站观察”而非共识事实。
