### 站点定位与公开内容分布

- 来源 URL：
  - https://www.michaelcaloz.com/personality/
  - https://www.michaelcaloz.com/find-or-confirm-your-type/
  - https://www.michaelcaloz.com/coaching-for-s-types/
- 证据：
  - 站点的核心入口是 `The Michael Caloz Cognitive Functions Test`，定位不是纯 MBTI 资讯站，而是 `测试 + 结果解释 + 判型辅导 + 教练转化页` 的一体化站点。
  - 公开 typology 内容明显偏向 `N types`：站内导航长期只挂出 8 个 N 型页面、3 篇常见混淆对比文，以及 1 个统称 `S types` 的总页。
  - `find-or-confirm-your-type` 明确写出作者更常接触 `NTP / INTJ / INFJ / NFP`，这解释了为什么公开资料在这些类型上远比 SJ / SP / SFJ / STJ 细。
  - `S types` 页面不是 8 个 S 型的类型页合集，而更像“如果你是 sensor，也可以来找我做 grounded / practical coaching”的介绍页，因此本站对 S 型的知识价值显著弱于对 N 型的价值。
- 覆盖问题：A1, B1, B12

### 测试页中的理论立场与评分逻辑

- 来源 URL：
  - https://www.michaelcaloz.com/personality/
- 证据：
  - 站点明确反对只停留在四字母刻板印象，主张要把 16 型继续拆到 `Jungian cognitive functions` 去理解。
  - 测试页先给出四维的生活化解释：
    - `I / E` 主要关乎如何恢复精力，不等于安静或爱社交。
    - `S / N` 主要关乎新信息摄取方式：更偏事实与感官，还是偏模式、想象和可能性。
    - `T / F` 主要关乎决策视角：更偏客观分析，还是更偏价值与对人的影响。
    - `P / J` 主要关乎面向外部世界的态度：更偏开放延展，还是更偏组织推进。
  - 页面强调 16 型之所以更有辨识度，是因为每种类型都由 `4 个功能` 组成，而且顺序固定为 `primary / auxiliary / tertiary / inferior`；作者把主导位写成最自然、常无意识的功能，把劣势位写成最晚成熟、也最容易成为盲点的部分。
  - 结果页逻辑不是“给一个唯一真相”，而是先给 `ranked potential results`。页面明确说 fit score 只是起点，最终仍由用户结合功能说明来确认自己的类型。
  - 打分方式不是简单相加。作者说明自己会对不同题组施加不同权重，再汇总成类型匹配度；新版结果页用 `Fit Bar` 展示近似匹配程度，并保留更细的原始分值。
  - 页面专门用 `INTJ vs INTP` 与 `INTP vs ENTP` 举例，强调“字母相似”不等于“认知接近”：有的类型三字母相同但功能完全不同；有的类型虽然一外一内，却只是同一组功能顺序不同。
- 覆盖问题：A1, A5, A6, B3, B4, B12

### 判型误差来源与校正建议

- 来源 URL：
  - https://www.michaelcaloz.com/find-or-confirm-your-type/
- 证据：
  - 这页把“正确判型”当成一个需要多重校正的过程，而不是“做一次测试就结束”。作者建议用户：
    - 先认真学功能而不是只背四字母；
    - 回看更早期、更自然的自己，而不是只看被社会塑形后的现在；
    - 用“什么让你恢复能量”而不是“你在极端场景里是否外向”来区分 I/E；
    - 让身边人一起读类型页，帮助校准自我盲区；
    - 警惕自己因为崇拜某种类型或排斥某种类型而带来的自我投射。
  - 作者明确说“给别人判型很难”，因为同样的外在行为背后可能是完全不同的内在动机；他甚至写到自己通常需要一小时以上，甚至多次会谈，才会更有把握地下判断。
  - 页面系统列出常见误判来源：
    - 文化环境会让人更像某个社会鼓励的维度；
    - 工作角色和适应策略会制造“后天训练出来的假外显”；
    - 理想自我会让人按“我想成为谁”答题；
    - 年龄和发展阶段会让第三/劣势功能看起来还没稳定；
    - 抑郁、焦虑、创伤、神经多样性都可能把某些功能表象放大。
  - 在创伤与神经多样性部分，作者特别提醒：
    - 创伤导致的过度警觉，可能让人看起来更像 `Se`；
    - 解离可能表现成 `Ti` 或 `Ni` 风格；
    - 自闭特征可能让人显得更内向或更 Thinking；
    - ADHD 与 `P`，尤其 `NP`，可能存在一些相关，但公开研究和个体案例都不足以下结论。
  - 这页的价值不在“定义功能”，而在提醒后续整理 persona 时，不能把所有外显行为都直接当成类型本体，必须给“掩饰、创伤、职业训练、desired self-image”留缓冲空间。
- 覆盖问题：A1, A11, B3, B8, B12

### NTP：开放探索 vs 深度求真

- 来源 URL：
  - https://www.michaelcaloz.com/coaching-for-entps/
  - https://www.michaelcaloz.com/coaching-for-intps/
  - https://www.michaelcaloz.com/2021/01/31/entp-or-intp/
- 证据：
  - `ENTP` 页面把该类型写成高开放、喜欢辩论、脑中会自己扮演 devil's advocate 的人；他们讨厌官僚和物流性收尾，最爱新项目刚开始的 brainstorming 阶段，习惯快速说话、边说边想、和别人来回碰撞观点。
  - 该页把 ENTP 的典型卡点写成：难以收束选择、容易为了辩而辩、容易把“直说真话”放到他人感受之上、对 routine 与 bureaucracy 强烈抗拒。作者给出的成长方向是：主动删减选项，并把注意力从“论点细节”拉回“这场争论本身是否有用”。
  - `INTP` 页面则把该类型写成更偏“内部求真”的深度分析者：看重逻辑正确性、会被社交暗示和办公室政治烦到、常因想把问题从所有角度想透而卡在过度分析里，也更容易在社交情境下不自在。
  - 对比文章把两者差异写得更具体：
    - `ENTP` 更像通过外放讨论来理解概念，更享受说服、辩论、即兴讲述，声音和表达通常更有起伏；
    - `INTP` 更像需要先独处深挖再发言，更追求论证严密、证据充分，希望别人看完逻辑链自然信服。
  - 在 `recharging energy` 上，作者把 ENTP 写成“和有意思的人待完以后会被激发”，而 INTP 更常是“和有意思的人待完以后觉得不错，但之后需要大量独处回血”。
  - 在 `social situations & judgment` 上，文章写 ENTP 更可能喜欢成为注意力中心、即兴开讲、拿人开玩笑；INTP 更可能是社交焦虑、更难读懂人际暗流、对别人的逻辑漏洞更不耐烦。
  - 在 `under stress` 上，作者给出的区分很适合后续 persona：
    - ENTP 压力下会执着于“我必须保有全部选择和全部可能”，随后转入怀旧、低动力、想把一切打扫整理好的状态；
    - INTP 压力下会执着于证明别人不理性、疯狂抠逻辑，同时变得异常敏感、觉得自己不被爱、很容易陷入“我必须证明自己是对的”。
  - 在 `what paralyzes them` 上，ENTP 更容易被官僚、流程和群体羞耻感冻住；INTP 更容易被“没有客观正确答案的抉择”和对权威的复杂投射卡住。
- 覆盖问题：A2, A3, A4, A8, A9, A11, B1, B2, B5, B8, B9, B11, B12

### NTJ：愿景执行与控制议题

- 来源 URL：
  - https://www.michaelcaloz.com/coaching-for-entjs/
  - https://www.michaelcaloz.com/coaching-for-intjs/
  - https://www.michaelcaloz.com/2025/04/02/intj-or-intp/
- 证据：
  - `ENTJ` 页面把该类型写成天然领导者：目标清晰、能动员别人、把大图景快速推进成结果；其阴影面则是对低效和无能极不耐烦、难表达脆弱、容易控制过度、难放松和接纳反馈。
  - `INTJ` 页面则突出“高标准的长期架构师”：会持续设定并迭代高难度目标，用逻辑不断修正路径；但也容易社交孤立、完美主义、对自己和别人期待过高，并倾向把情绪和脆弱压得很深。
  - `INTJ vs INTP` 对比文把 INTJ 的核心驱动力概括成：
    - 更关心什么 `effective`；
    - 喜欢把知识转成长期战略和系统解决方案；
    - 重视能力、效率和可执行的结构；
    - 容易因为别人显得慢、绕、低效而想 micromanage。
  - 同文把 INTP 作为对照写成：
    - 更关心什么 `true`；
    - 为了理解而学习，不一定需要外部用途；
    - 更想保留选择，不喜欢被目标框住；
    - 容易因找不到完美方法而一直不行动。
  - 在 `structure / planning / action` 上，文章把 INTJ 写成更能 commit to a vision，但也可能因想把计划做得太完美而延迟动作；INTP 则更容易因方法论不确定和选项过多而掉进 analysis paralysis。
  - 在 `stress` 上，INTJ 被写成会走向更强控制、完美主义、身体层面的极端 push 或冲动放纵，同时更轻视情绪和混乱的人类需求；这对后续写 Ni-Te/Se 压力场景很有参考价值。
- 覆盖问题：A2, A3, A4, A8, A11, B1, B2, B3, B4, B5, B8, B11, B12

### NF：价值、共情与理想驱动

- 来源 URL：
  - https://www.michaelcaloz.com/coaching-for-enfps/
  - https://www.michaelcaloz.com/coaching-for-infps/
  - https://www.michaelcaloz.com/coaching-for-enfjs/
  - https://www.michaelcaloz.com/coaching-for-infjs/
- 证据：
  - `ENFP` 页面把 ENFP 写成高能、会感染气氛、适合面向人群表达和激励的人；但同页也强调他们高度依赖外界肯定、需要独处去消化感受，并且在被压制表达、被过度管理时很容易关机或郁闷。
  - ENFP 页还明确写到其压力形态可能转成 `nitpicky / controlling / depressed` 并从关系中抽离，这为后续写 Ne-Fi 在失衡时的反差提供了直接证据。
  - `INFP` 页面把 INFP 的驱动力压到“个人完整性与价值一致”：他们不是用社会标准判断对错，而是要先确认这件事是否真和自己的价值观对齐；同时他们想象力强、内在世界丰沛、对他人情绪高度共振，但也更容易被情绪淹没、回避冲突、被理想与现实差距伤到。
  - `ENFJ` 页面突出其群体导向和照顾者角色：关系是核心资产，会主动照看他人需求、鼓舞和组织群体；代价是容易过度承诺、压抑自己的不满来维持和谐、把批评听得过重。
  - `INFJ` 页面把 INFJ 写成“自然的咨询者”：能看见别人表层之下发生的事，也会通过持续扫描别人情绪与需求来获得安全感；这让他们极易过度付出、后知后觉地耗尽自己，然后退回隔离与自我审判。
  - 这 4 页共同说明：Michael Caloz 对 NF 类型的写法很少停留在“温柔、善良、理想主义”这样的通用词，而更聚焦于 `关系敏感度 + 自我边界 + 理想/现实落差 + 在压力下如何失衡`。
- 覆盖问题：A2, A3, A8, A9, A11, B1, B2, B5, B8, B9

### INFJ vs INFP：Ni-Fe 与 Fi-Ne 的场景化分叉

- 来源 URL：
  - https://www.michaelcaloz.com/2024/04/27/infj-or-infp-how-to-tell-the-difference/
  - https://www.michaelcaloz.com/coaching-for-infjs/
  - https://www.michaelcaloz.com/coaching-for-infps/
- 证据：
  - 这篇对比文最有价值的地方，是它不是抽象讲功能，而是用多个具体情境去演示两型的第一反应。
  - 在“朋友正在做糟糕选择”这个情景里：
    - INFJ 更像先看见长期模式和后果，再思考如何包装建议，让对方真的会听进去；
    - INFP 更像先感到“这不符合他真正的自我”，然后努力在不压过对方自主性的前提下说出自己真实的价值判断。
  - 在“被邀请领导一个项目”时：
    - INFJ 会自然想到愿景、团队动员和整体落地；
    - INFP 则先问“我真信这个吗？如果带队，能不能按我认为真实的方式做？”
  - 在“和朋友对某个问题意见不同”时：
    - INFJ 会先退后一步校准问题定义、拆假设、增加逻辑清晰度；
    - INFP 则会更快把注意力拉到“哪种做法最实用、最快落地”，这说明作者在这里刻意强调了 INFP 的现实执行侧，而不是只写成纯理想主义者。
  - 在“和在乎的人发生冲突”时：
    - INFJ 更想找到表层争执下的深层断裂，再把双方带回共同 ground；
    - INFP 更强调不能为了表面和谐而背叛自己的真实感受或核心价值。
  - 这篇文章很适合后续写 `INFJ vs INFP` 的 prompt 区分，因为它提供了非常接近内心独白的准例句，不只是标签。
- 覆盖问题：A4, A10, B4, B6, B10, B11, B12

### INTJ vs INTP：战略执行 vs 理论校准

- 来源 URL：
  - https://www.michaelcaloz.com/2025/04/02/intj-or-intp/
  - https://www.michaelcaloz.com/coaching-for-intjs/
  - https://www.michaelcaloz.com/coaching-for-intps/
- 证据：
  - 这篇对比文的核心区分是 `effectiveness` 和 `truth-seeking`：
    - INTJ 更容易问“怎样把这些洞察变成推进目标的战略？”
    - INTP 更容易问“事情到底如何运作？哪种模型更准确？”
  - INTJ 段反复出现的关键词是：长期愿景、系统级解决方案、结构、效率、掌控、能力标准；文章明确写到他们可能因别人显得慢或不理性而烦躁，并更愿意调整外部系统来逼近目标。
  - INTP 段反复出现的关键词则是：概念清晰、内部框架、自主思考、开放选项、为了理解而理解；他们更可能因没有完美答案或公开暴露不成熟成果而拖延。
  - 对比文对压力态的拆分也很具体：
    - INTJ 容易卡在过度规划、刚性控制、忽视身体和情绪需求，甚至走向冲动放纵或体能极限化；
    - INTP 容易卡在犹豫、理论逃避、羞耻感、过度敏感和“必须证明我逻辑正确”的执念。
  - 文末给的“更偏好的工作”也揭示作者对两型的理解：
    - INTP 更偏理论模型、抽象系统和纯理解；
    - INTJ 更偏把理解转成应用、战略、工程和优化。
- 覆盖问题：A4, A10, A11, B3, B4, B8, B10, B11, B12

### S types 页：公开资料盲区

- 来源 URL：
  - https://www.michaelcaloz.com/coaching-for-s-types/
- 证据：
  - 该页公开能回收的信息很有限，重点不在“sensor 如何运作”，而在“如果你是更偏 concrete / practical 的人，我也能用接地气的方法帮你改变生活”。
  - 公开文本最明确的 typology 相关信息有三点：
    - 作者承认自己主要专长是 N types；
    - 也曾服务过不少 S types，尤其提到 `ISTP / ESTP / ESFP / ISFP`；
    - 这类用户更可能共鸣于 `concrete tools / real-world applications / grounded practical support`。
  - 但这页没有：
    - 8 个 S 型分别的人设；
    - S/N 功能级解释；
    - SJ / SP / STJ / SFJ 的区分；
    - 可直接提取到 persona 的对话示例。
  - 因此本站若用于后续 16 型完整 persona 构建，只能把 `S types` 页当作“作者自己承认的覆盖盲区”记录，而不能当作 sensor 类型的主要证据源。
- 覆盖问题：A1, B1

## 交叉验证提示

- 本站最强的不是纯理论定义，而是 `mistyping nuance + lived challenges + coaching-language portraits`。后续抽取 persona 时很适合补“卡点、羞耻点、压力下会怎么歪”。
- 本站公开内容有明显 `N-type bias`。如果后续要写 `ISTJ / ISFJ / ESTJ / ESFJ / ISTP / ESTP / ISFP / ESFP`，不能把这里当主站，只能当补充。
- 站内不少页面本质是结果页或教练落地页，所以常把类型问题直接翻译成“如何成长、如何不卡住”，这和 `totypes / typeinmind / psychologyjunkie` 的学理写法不同，后续整合时要区分“功能定义”与“成长建议”。
