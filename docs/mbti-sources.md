# MBTI 认知功能信息源清单

> 共 25 个条目，去重后 **22 个唯一域名**（按类别分组，部分站点跨类别重复出现）。
> 全量爬取目标 = 22 个唯一域名。

---

## 一、英文专业网站（认知功能深度分析）

1. **Psychology Junkie** — psychologyjunkie.com
   认知功能最全面的英文站点之一，每个功能都有独立深度文章，包含争论风格分析
   推荐文章：Introduction to Cognitive Functions / Arguing Style by Type

2. **Personality Junkie** — personalityjunkie.com
   Dr. A.J. Drenth 运营，学术性强，功能栈理论解释最清晰
   推荐文章：The Function Stack (Typology 301)

3. **Type in Mind** — typeinmind.com
   每个类型用认知功能命名（NiFe = INFJ），按功能栈逐一解释，避免了字母刻板印象

4. **Personality Hacker** — personalityhacker.com
   Joel Mark Witt 团队运营，用「Car Model」比喻功能栈（驾驶员/副驾驶/后座小孩/婴儿），非常直观

5. **Michael Caloz Cognitive Functions Test** — michaelcaloz.com/personality
   认知功能测试设计者，测试本身就是很好的功能定义参考

6. **Cognitive Processes** — cognitiveprocesses.com
   Linda Berens 博士的站点，16 种类型的动力学模型，含 Dominant/Auxiliary/Tertiary/Inferior 详解

7. **MBTI.cat** — mbti.cat/en/functions
   120+ 类型组合分析，含情绪健康、压力反应、沟通风格

8. **Personality-Type.com** — personality-type.com/cognitive-functions-of-mbti
    含影子功能（5-8位），对产品来说可能太深但值得了解

9. **JobCannon — MBTI Cognitive Function Stacks** — jobcannon.io/blog/cognitive-function-stacks-mbti
    功能栈完整表格 + 压力反应（grip behavior）详解，非常实用

10. **TypeMyVibe** — typemyvibe.ai/blog/mbti-types/entp
    每个类型有「这个人在对话中会怎么说话」的真实例句，直接可用于 prompt

## 二、MBTI 冲突/沟通风格（对 Perso 最直接有用）

11. **Myers-Briggs Official Conflict Style Report** — myersbriggs.org
    官方冲突风格报告，按 TJ/TP/FJ/FP 四种冲突对分析，最权威

12. **MBTIonline — Type and Conflict** — mbtionline.com
    每个类型的冲突触发点、应对方式，直接可用

13. **Psychology Junkie — Arguing Style by Type** — psychologyjunkie.com
    16种人格的争论方式逐一分析，含真实案例和评论区用户反馈
    ⚠️ 同上站（与条目 1 同域名 psychologyjunkie.com，爬取时合并到一个 raw 文件）

## 三、中文深度资源

14. **不可解的Luca（lucaluo.com）** — lucaluo.com/mbti-introduction
    目前见到的最好的中文认知功能解析，Car Model 比喻用得很好，有系列文章

15. **知乎：mbti与荣格八维资料-若化生**
 — https://zhuanlan.zhihu.com/p/112590609
 — https://zhuanlan.zhihu.com/p/117951832
 — https://zhuanlan.zhihu.com/p/561525061和该页面中引用的16人格类型的子页面
含约翰·毕比的原型理论（英雄/父母/儿童/劣势），功能发展阶段解析，非常深

16. **荣格认知功能测试（jungus.cn）** — jungus.cn/test
    专业版 72 题，基于深层荣格心理学，测试设计本身就是好的功能定义参考

17. **Totypes（totypes.com）** — totypes.com
    荣格八维认知动力，区分了 MBTI 和荣格八维是「同父异母」的模型

## 四、学术/官方资源

18. **Myers-Briggs Official** — myersbriggs.org
    官方类型动力学页面，Dominant/Auxiliary/Tertiary/Inferior 定义，含压力反应
    ⚠️ 同上站（与条目 11 同域名 myersbriggs.org，爬取时合并到一个 raw 文件）

19. **Myers-Briggs Personal Impact Report** — themyersbriggs.com
    官方个人影响报告样本，含沟通风格、冲突风格、压力反应

20. **Truity — Beginners Guide to Cognitive Functions** — truity.com
    入门级但准确，每个功能的行为表现和对应类型

21. **AssessFirst — Cognitive Functions MBTI** — assessfirst.com
    欧洲视角的功能解析，偏商业应用但功能定义清晰

## 五、测试工具（了解功能定义的另一个角度）

22. **Sakinorva** — sakinorva.net
    最受认知功能爱好者推荐的测试，按功能而非字母打分

## 六、社区/讨论（真实用户的自我描述，对 prompt 校准最有价值）

23. **Personality Cafe** — personalitycafe.com
    每个类型有独立论坛，用户自述「我是 INTJ，我在争论中会这样反应」，是最真实的素材

24. **知乎社区问答** — zhihu.com（问答区，区别于条目 15 的专栏文章）
    大量「INTJ 和 ENFP 吵起架来会怎样」「哪个 MBTI 类型最爱杠人」等问题，真实用户回答
    ⚠️ 同域名（与条目 15 同域名 zhihu.com，爬取时合并到 zhihu.md，或单独建 zhihu-community.md）
    推荐搜索词：`MBTI 吵架`、`MBTI 争论`、`[类型] 被怼`、`[类型] 圆桌`

25. **小红书 — MBTI 话题** — xiaohongshu.com
    中文用户自述「作为 INFP 被 ENTJ 说了什么感受」「MBTI 圆桌聚会」等场景，例句密度最高
    推荐搜索词：`MBTI 争论`、`MBTI 圆桌`、`[类型] 吵架`、`[类型] 说话风格`
