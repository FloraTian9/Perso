### 8 功能总览与理论入口

- 来源 URL：
  - https://mbti.cat/en/functions
  - https://mbti.cat/en/cognitive-functions
  - https://mbti.cat/en/overview-cognitive-functions
- 证据：
  - 站点把认知功能先拆成 `四种认知过程`：
    - `Sensing` 依赖具体事实和细节
    - `Intuition` 依赖推测性想法与可能性
    - `Thinking` 依赖系统化、非人格化判断
    - `Feeling` 依赖价值评估与人际/自我感受
  - 再把每种过程区分为 `外倾 e` 与 `内倾 i` 两种取向：
    - 外倾取向把心理能量导向外部对象与事件，偏行动和活动
    - 内倾取向把心理能量导向主观经验，偏反思和个体化
  - `functions` 页给 8 功能都配了 `站内昵称 + 一句话功能抓手 + 主导/辅助类型`：
    - `Ne / Extraverted Intuition / Possibility Explorer`：探索无限可能、看见意外连接；主导 `ENTP ENFP`，辅助 `INTP INFP`
    - `Ni / Introverted Intuition / Visionary Strategist`：可视化未来、预见长期后果；主导 `INTJ INFJ`，辅助 `ENTJ ENFJ`
    - `Se / Extraverted Sensing / Sensory Adventurer`：活在当下、追求强烈体验；主导 `ESTP ESFP`，辅助 `ISTP ISFP`
    - `Si / Introverted Sensing / Memory Guardian`：保存传统、重视过往经验；主导 `ISTJ ISFJ`，辅助 `ESTJ ESFJ`
    - `Te / Extraverted Thinking / Logical Organizer`：优化系统、建立高效结构；主导 `ESTJ ENTJ`，辅助 `ISTJ INTJ`
    - `Ti / Introverted Thinking / Systems Analyst`：分析逻辑原则、追求内部一致；主导 `ISTP INTP`，辅助 `ESTP ENTP`
    - `Fe / Extraverted Feeling / Social Harmonizer`：创造社会和谐、看重共同体连接；主导 `ESFJ ENFJ`，辅助 `ISFJ INFJ`
    - `Fi / Introverted Feeling / Values Defender`：维护个人完整性、捍卫深层价值；主导 `ISFP INFP`，辅助 `ESFP ENFP`
  - `overview-cognitive-functions` 额外强调四类功能群的外显倾向：
    - 外倾感知功能偏冒险、即兴、快速抓外部机会
    - 内倾感知功能偏反刍、内化和主观整合
    - 外倾判断功能偏组织环境、协调外界
    - 内倾判断功能偏个人原则、内部校准
- 覆盖问题：A1, A2, A3, A5, A6, B3, B4

### 16 型总览页

- 来源 URL：
  - https://mbti.cat/en/types
- 证据：
  - 该页把 16 型按 `NT / NF / SJ / SP` 四组展示，并给出每型 `一句话定位 + 功能栈 + 3 个标签 + 4 个功能在 adaptive / unconscious / unhealthy 三栏下的变化词`。
  - 四大气质组的总括语：
    - `NT`：理性、客观，追求知识与能力
    - `NF`：共情、理想主义，追求真实与和谐
    - `SJ`：负责、务实，追求秩序与稳定
    - `SP`：自发、适应性强，追求自由与体验
  - 16 型短画像与功能变化词如下：
    - `INTJ / Ni-Te-Fi-Se`：`The Architect`，有全局计划的远见战略家；标签 `Strategic / Independent / Analytical`；Ni 适应态 `perceptive, insightful`，失衡态 `insular, presumptuous`；Se 失衡态 `self-indulgent, extreme`
    - `INTP / Ti-Ne-Si-Fe`：`The Logician`，饥渴求知的创新思考者；标签 `Analytical / Curious / Objective`；Ti 适应态 `systematic, precise`，失衡态 `reductive, arrogant`；Fe 失衡态 `cynical, temperamental`
    - `ENTJ / Te-Ni-Se-Fi`：`The Commander`，大胆、富想象力、意志强的领导者；标签 `Leader / Efficient / Strategic`；Te 适应态 `factual, effectual`，失衡态 `inflexible, overbearing`
    - `ENTP / Ne-Ti-Fe-Si`：`The Innovator`，停不下来的智性挑战者；标签 `Resourceful / Curious / Innovative`；Ne 适应态 `optimistic, inventive`，失衡态 `frivolous, unrealistic`
    - `INFJ / Ni-Fe-Ti-Se`：`The Counselor`，安静神秘但能鼓舞人的理想主义者；标签 `Empathetic / Visionary / Idealistic`
    - `INFP / Fi-Ne-Si-Te`：`The Mediator`，总能看见他人善意的利他诗人；标签 `Idealistic / Creative / Authentic`；Fi 失衡态 `moody, self-absorbed`
    - `ENFJ / Fe-Ni-Se-Ti`：`The Protagonist`，有感染力、能鼓舞人群的领导者；标签 `Charismatic / Inspiring / Altruistic`
    - `ENFP / Ne-Fi-Te-Si`：`The Activist`，热情自由、创造力强、社交性高；标签 `Enthusiastic / Creative / Sociable`
    - `ISTJ / Si-Te-Fi-Ne`：`The Logistician`，讲事实、可信、负责；标签 `Responsible / Organized / Practical`；Si 失衡态 `closed, limited`
    - `ISFJ / Si-Fe-Ti-Ne`：`The Defender`，忠诚守护者，随时准备保护亲近者；标签 `Dedicated / Warm / Practical`
    - `ESTJ / Te-Si-Ne-Fi`：`The Executive`，擅长管理的执行型管理员；标签 `Organized / Direct / Responsible`
    - `ESFJ / Fe-Si-Ne-Ti`：`The Consul`，格外体贴、善社交、受欢迎；标签 `Caring / Cooperative / Practical`
    - `ISTP / Ti-Se-Ni-Fe`：`The Virtuoso`，大胆务实的实验者和工具高手；标签 `Practical / Observant / Adaptable`
    - `ISFP / Fi-Se-Ni-Te`：`The Adventurer`，灵活、有魅力、随时想探索的艺术家；标签 `Artistic / Sensitive / Flexible`
    - `ESTP / Se-Ti-Fe-Ni`：`The Entrepreneur`，聪明、精力强、活在边缘的现实观察者；标签 `Energetic / Perceptive / Bold`
    - `ESFP / Se-Fi-Te-Ni`：`The Entertainer`，即兴、热情、永远不无聊；标签 `Spontaneous / Enthusiastic / Sociable`
  - 这个总览页对每型都给了 `四个功能的三种状态词`，可直接作为后续 persona 文件里的 `成熟/半意识/不健康` 证据池。例如：
    - `ENTP`：Ne 从 `optimistic, inventive` 走向不健康时会变成 `frivolous, unrealistic`
    - `ESTP`：Ni 的不健康词是 `gloomy, paranoid`
    - `INFP`：Te 的半意识词是 `passive`，不健康词是 `obstinate, harsh`
    - `ESFJ`：Ti 的不健康词是 `calculating, censorious`

### 镜像功能与易混淆对

- 来源 URL：
  - https://mbti.cat/en/distinguishing-mirror-functions
- 证据：
  - 站点把 `Si/Ni`、`Se/Ne`、`Ti/Fi`、`Te/Fe` 定义为 `mirror functions`，指出它们 `结构相似但处理的内容不同`，所以表面行为像、底层机制未必一样。
  - 页面明确提醒：功能越低位、越不健康、越无意识，就越容易把一个功能误认成镜像功能。
  - 给出的四组辨析主题：
    - `Si-Ne & Ni-Se`：都可能表现出对外界的不安或警惕，但焦点不同
    - `Se-Ni & Ne-Si`：都可能表现得兴奋地面向外界，但一个偏即时体验，一个偏可能性扩张
    - `Ti-Fe & Fi-Te`：都涉及“相信自己”，但一个以逻辑自洽为轴，一个以价值一致为轴
    - `Te-Fi & Fe-Ti`：都可能诉诸“正确做事”，但一个偏外部标准/效率，一个偏关系秩序/群体合理性
  - 站点的辨析原则不是列刻板印象，而是强调：`观察细节、观察处理内容、不要只看表面行为`。
- 覆盖问题：A4, B12

### 类型发展与功能栈动态

- 来源 URL：
  - https://mbti.cat/en/type-development
- 证据：
  - 站点沿用 `dominant / auxiliary / tertiary / inferior` 的发展顺序，并给四个栈位起了叙事化名字：
    - 主导位 `The Dominant Hero`
    - 劣势位 `The Inferior Enemy`
    - 辅助位 `The Auxiliary Sidekick`
    - 第三位 `The Tertiary Temptation`
  - 它认为主导功能大约在 `6-12 岁` 明显分化，并逐渐成为个体构建自我叙事的核心。
  - 劣势功能与主导功能呈拉扯关系；为了维持自我一致性，人会自然站在主导一边，把劣势压到更无意识的地方。长期压抑后更容易以 maladaptive 形式反扑。
  - 辅助功能被写成 `release valve`：如果主导功能走极端，真正能缓和主导/劣势张力的是辅助，而不是直接硬顶劣势。
  - 第三位 loop 被写成一种 `double down strategy`：人在主导失效时，不是补辅助，而是拉第三位来替主导护航，短期有力量感，长期制造更多问题。
  - 页面同时把发展障碍归为：精神障碍、环境压力、低自尊、ego defense mechanisms 等，不把一切问题都归因为“你是某类型”。
  - 在功能成长阶段上，站点区分：
    - `underdeveloped`：多数无意识、幼稚表达、结果偏负面
    - `developing`：半意识、天真表达、结果好坏混杂
    - `developed`：多数有意识、成熟表达、结果偏正面
- 覆盖问题：A5, A11, B8

### Persona 与外部适应方式

- 来源 URL：
  - https://mbti.cat/en/ego-and-persona
- 证据：
  - 页面把 `persona` 定义为人与外部世界建立关系时所使用的身份面具，并明确说它和 `ego development` 是连在一起的。
  - 站点特别用 `Te/Fe 在栈中的位置` 来解释 persona 风格：
    - `Dominant Te/Fe` 的 `EJ` 更容易建立追求外部成就和影响力的 persona，若失衡会变成过度识别社会角色与控制成果
    - `Inferior Te/Fe` 的 `IP` 更容易走向逆反型 persona，强调“不按常规来”，但也可能因此忽视现实责任和外部适应
    - `Auxiliary Te/Fe` 的 `IJ` 会在内在主观世界和外部成就需求之间持续拉扯，更容易形成“退守型” persona
    - `Tertiary Te/Fe` 的 `EP` 会把外部适应当成临时变形工具，若失衡会让 inner life 变薄、persona 变得漂浮
  - 页面给出若干失衡画像：
    - `ExTJ` 容易投射出 `impenetrable` 的强硬能干形象，不愿面对脆弱与无力
    - `IxTP` 容易投射 `indifferent` 的“我什么都不在乎”形象，用冷淡掩护不安全感
    - `IxTJ` 容易出现 `retreating persona`
    - `ExFP` 容易出现 `flaky persona`，为了逃离负面感受而不断变形
- 覆盖问题：A5, B1, B8

### 情绪健康与压力管理

- 来源 URL：
  - https://mbti.cat/en/emotional-health
  - https://mbti.cat/en/health-and-stress
- 证据：
  - `emotional-health` 明确把 `认知功能` 与 `情绪功能` 区分开：二者彼此影响，但情绪调节能力不应直接从类型刻板印象推断。
  - 页面对 `emotional intelligence` 的立场是：它主要是可学习能力，而不是天生随类型固定；核心包括两组能力：
    - `感知情绪`：觉察情绪、知道触发点、识别他人情绪、预判他人情绪
    - `管理情绪`：命名情绪、处理高情绪状态、恰当表达、照顾自己和他人的情绪需要
  - `emotional awareness` 章节强调情绪首先是生理反应，进入意识后才被解释成 feelings；若缺少身体觉察与正念窗口，人更容易被情绪 hijack。
  - `health-and-stress` 则把压力管理放回通用身心卫生层面，不按类型细分，而是强调：
    - 睡眠是情绪调节、学习记忆和执行功能的基础
    - 饮食和肠道健康显著影响焦虑、抑郁和认知状态
    - 运动是重要的情绪调节工具
    - 压力管理不能只靠“想通了”，也要靠身体节律和生活结构
  - 也就是说，本站在 A11/B8 上的特色不是写很多“某型发疯会怎样”，而是提醒 `类型问题常与普遍的情绪调节和生活卫生交织`。
- 覆盖问题：A11, B7, B8

### 情绪触发模式

- 来源 URL：
  - https://mbti.cat/en/emotional-triggers
- 证据：
  - 页面把 `trigger` 定义为 `可预测地引发情绪唤起的刺激模式`，核心建议是通过身体信号和早期反应去更早捕捉情绪螺旋。
  - 站点按功能对/气质组归纳常见触发源：
    - `SJ`：缺少细节、一致性、准备度时容易被触发
    - `NP`：缺少灵感、机会、进展时容易被触发
    - `NJ`：表面化、无目标、缺少前瞻性时容易被触发
    - `SP`：缺少刺激、参与感、行动自由时容易被触发
    - `TP`：不准确、不连贯、无能时容易被触发
    - `FJ`：人际冲突、反社会行为、内疚羞耻时容易被触发
    - `FP`：虚伪、不真实、被无效化对待时容易被触发
    - `TJ`：被动、低效、缺规划/组织时容易被触发
  - 页面还特别指出：当某功能 `underdeveloped or lower in the stack` 时，人也会被该功能的反面刺激到。例如：
    - 低或失衡 `Ne` 容易被 `impracticality / too much novelty / abrupt change / pessimism` 触发
    - 低或失衡 `Te` 容易被 `setbacks / impersonal rules / purely objective decision-making` 触发
    - 低或失衡 `Fe` 容易被 `dependence issues / emotional bias / relational intimacy / social pressures` 触发
  - 这页非常适合后续做人格冲突触发器，而不是直接拿来写日常说话风格。
- 覆盖问题：A2, A11, B2, B8, B11

### 情绪需求与支持方式

- 来源 URL：
  - https://mbti.cat/en/caring-for-emotional-needs
- 证据：
  - 页面先区分 `内倾者` 与 `外倾者` 的处理方式：
    - 内倾者通常向内消化情绪，容易在过载前不显山露水，因此需要更早表达
    - 外倾者通常通过说出来或做点什么处理情绪，若不反思可能把行动一路推到 crisis
  - 对“如何帮助别人”给出的原则是：不要按自己的价值系统给帮助，而要按对方被触发的功能需要给帮助。
  - 8 功能的情绪需要被概括为：
    - `Si needs`：稳定、扎根、优先级、仪式感、可分解的步骤
    - `Ni needs`：值得追求的目标与理想、可行计划、意义感
    - `Ti needs`：独立处理个人兴趣与能力、界定责任边界
    - `Fi needs`：真实表达、边界、自我同情、尊重脆弱性
    - `Se needs`：活动、刺激、冒险、乐趣、工作生活平衡
    - `Ne needs`：新点子、变化、进步、创造性解决问题、乐观感
    - `Te needs`：有生产性的工作、直面挑战、清除障碍、效率感
    - `Fe needs`：与更大共同体相连、关系投入、共享负担、借集体智慧解题
  - 页面还补了支持策略：
    - 要明确说出自己现在是 `需要空间`、`需要回头处理某件事`、`需要把感受说出来`，还是 `需要解决思路`
    - 对内倾者，别把沉默直接读成冷漠
    - 对外倾者，别把情绪外放直接读成失控或恶意
- 覆盖问题：A2, B2, B8, B11

### 冲突沟通与关系摩擦

- 来源 URL：
  - https://mbti.cat/en/communicating-through-conflict
  - https://mbti.cat/en/relationship-dynamics
- 证据：
  - `communicating-through-conflict` 不是按 16 型写争吵风格，而是给出一套普适的冲突修复路径：
    - 第一步先停掉 `war mindset`
    - 区分 `The Truth About Me` 与 `The Truth About Them`
    - 把 blame 改写成 `感受 + 原因 + 需要/请求`
    - 区分 `requests vs demands`
  - 页面用洗碗例子对比两种表述：
    - blame 句式：`You are so lazy, always leaving dishes in the sink.`
    - need-based 句式：看到水槽堆满盘子让我很有压力，因为我时间很少，我需要更多帮助
  - 站点的冲突立场非常清楚：责怪会伤害对方的胜任感，让对方更难听进去；把诉求翻译成 needs，才更可能获得回应。
  - `relationship-dynamics` 则把摩擦写成 `过度使用某功能/取向` 的副作用：
    - 过度外倾：草率、匆忙、忽略细节，容易让慢节奏伴侣受伤
    - 过度内倾：过于被动、犹疑、错失机会，容易让高行动伴侣不耐烦
    - 高 `Se` 过度使用：太随意、把严重问题一拖再拖，令对方觉得关系不被认真对待
    - 高 `Ne` 过度使用：过度乐观、回避负面问题、不断变更承诺
    - 高 `Si` 过度使用：爱按自己的标准 fuss / nitpick，对人施加规则感
    - 高 `Ni` 过度使用：追求理想关系模板，容易把人往自己愿景里塑形，最后被现实反噬
  - 这些内容更适合提炼 `冲突触发点 / 修复建议 / 关系中的典型偏差`，而非直接当成逐型对话口头禅。
- 覆盖问题：A8, A9, B4, B6, B11

### 关系动态中的话题偏好与互动场景

- 来源 URL：
  - https://mbti.cat/en/relationship-dynamics
  - https://mbti.cat/en/relationship-pairs/enfj-istp
  - https://mbti.cat/en/relationship-pairs/enfp-istp
  - https://mbti.cat/en/relationship-pairs/isfp-istj
- 证据：
  - `relationship-dynamics` 把伴侣摩擦明确写成 `互动节奏和偏好失配`，而不只是“谁脾气更差”：过度外倾会让慢节奏伴侣觉得被催赶，过度内倾又会让高行动伴侣觉得对方总在错失时机；这直接补 `B7` 里的 `群体活动 / 外出频率 / 互动节奏` 差异
  - `ENFJ + ISTP` 的 pair 页给了很实用的话题与场景线索：`ENFJ` 不要逼 `ISTP` 参加太多 social activities，也要尝试理解对方那些自己会觉得 dull or boring 的兴趣；反过来 `ISTP` 需要更明确说明自己何时要 alone time，何时愿意 join in。这里已经不只是“关系建议”，而是在描述两类人对 `社交密度`、`兴趣话题`、`参与形式` 的天然反应差异
  - 同一页还把 `理想化谈话 vs 实际导向谈话` 的摩擦写得很直白：`ENFJ` 容易把关系带向“更好的样子”与愿景讨论，`ISTP` 则更容易把注意力放在实际问题、可操作建议、当下兴趣上；如果前者 push idealism 过重，后者会觉得 unrealistic 或被改造
  - `ENFP + ISTP` 的 pair 页进一步把 `抽象话题 vs 现实话题` 拆得很清楚：`ISTP` 偏 practical / sensory experience，容易把太多 abstract ideas 看成 impractical；`ENFP` 则更爱 human development、可能性和概念延展，反过来会觉得 `ISTP` uncreative or limited。页面甚至直接建议两人去找 `non-competitive shared activity`，并在 shared activities 上协商 `E/I balance`
  - `ISFP + ISTJ` 的 pair 页补上另一组典型 B7 轴线：`ISFP` 的 spontaneous / adventurous 容易把 `ISTJ` 的 routine、detail、established ways 体验成 boring 或 nitpicky；`ISTJ` 则会把 `ISFP` 的随性和跳跃读成 impulsive、hasty、erratic。这里已经能直接支撑后续人格文件里的 `对稳定日常话题、临时起意活动、没有明显实用价值的想法` 的不同反应
  - 把这几页合起来后，`mbti.cat` 对 B7 的贡献可以压缩成四条稳定维度：`抽象 vs 具体`、`一对一/独处 vs 高频社交`、`新鲜刺激 vs 规律秩序`、`讲愿景和感受 vs 讲问题和做法`。这类维度虽然不是逐型台词，但非常适合做后续人格文件中的 `话题偏好差异` 推导骨架
- 覆盖问题：B6, B7

### 120+ 关系配对与组合观察

- 来源 URL：
  - https://mbti.cat/en/relationship-pairs
- 证据：
  - 页面明确反对简单的“天生绝配”叙事，强调兼容性主要取决于 `情绪成熟度 + 沟通能力`，而不只是字母配对。
  - 站点说明 120+ 配对分析的底层视角是 `两个人的功能栈如何互补、冲突、形成吸引或误读`。
  - 它给出几条高层组合规则：
    - 两人共享同一主导功能时，常常能本能理解彼此，但也可能争抢同一认知空间
    - 一方主导恰好是另一方劣势时，常有强吸引，也常有高误解潜力
    - 真正的关系动力来自 `dominant / auxiliary / tertiary / inferior` 的整体相互作用
  - 该页是后续做跨类型互动与 pair prompt 的好索引，但 raw 阶段未逐对展开 120+ 全部组合。
- 覆盖问题：A7, B6, B12

## 交叉验证提示

- 本站把很多问题写成 `功能发展 / 情绪调节 / 关系修复` 语言，而不是标准 MBTI 社群里常见的 `grip / loop / blind spot` 术语密集写法；后续整理时要注意与 `jobcannon`、`personalityhacker`、`myersbriggs` 之类站点做术语映射。
- `health-and-stress` 页几乎不按类型拆分，而是强调睡眠、饮食、运动、压力卫生，这能补“高层压力管理”，但不能替代逐型冲突表现来源。
- `types` 页虽然覆盖 16 型，但只有总览级短描述和功能变化词，没有 `对话例句`、`说话节奏`、`具体冲突对白`。

## 失败/盲区记录

- 站内还有 `crushes`、`relationship-tips`、`career-satisfaction`、`learning-preferences`、`learning-function-development` 等扩展页；本次以知识库主任务为先，优先提取了功能理论、类型总览、情绪压力、冲突关系相关页面，未逐页完整展开。
- `relationship-pairs` 明示覆盖 `120+ type combinations`，但本次 raw 只记录其总原则，没有逐对抓取全部组合页。
- 本站缺少可直接复用的 `真实对话例句` 与 `逐型说话特征`，A10 / B9 / B10 需要后续由 `typemyvibe`、`personalitycafe`、`psychologyjunkie` 等站补齐。
