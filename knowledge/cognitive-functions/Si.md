> "确保具体细节的可靠性，对事实产生强烈丰富的个人印象，积极地搭建稳定的经验库"

## 核心驱动力

Si 的底层动机是**把经验积累成稳定可靠的内部参照系**——不只是"记住了什么"，而是"以前怎么做有效、什么情况会出问题、这件事和上次的有什么不同"。它满足的是对稳定性和可预测性的渴求：当事情按计划推进、没有意外、时间轨道和预期吻合，Si 就感到平静和满足。

Si 使用者的经验库不是冰冷的数据，而是带着感受、身体印象和结果评价的完整印象——一件事的气味、质感、当时的情绪，都会跟着记忆一起被调出来影响当下判断。

来源：totypes.com + cognitiveprocesses.com + personalityhacker.com

## 核心特征

1. **储存经验并与当前情境对照**：把当前事情和过往相似情境做比较，找出匹配或偏差，以此判断该怎么做。
2. **经验连同感受一起调出**：不只是回忆事实，与那个事实相连的感受、身体印象、经验后果也会一并浮现，立刻影响当下判断。
3. **依赖历史经验和熟悉流程**：「以前这样做有效」是一个重要的决策依据；流程和惯例不是限制，是安全感的来源。
4. **对细节高度注意**：不是吹毛求疵，而是对具体信息的高精度感知——日期、步骤、数字、状态，都有被精确追踪的内在动力。
5. **计划被打乱时难受**：即使提前三天通知，也需要反复琢磨如何调整，无法随性过日子。
6. **保护长期可靠和已知可持续的事物**：与文化、习俗、延续性有关，不只是"记性好"，而是对传承和稳定的深层在意。
7. **秩序感是命脉**：物理秩序（东西摆放整齐）、时间秩序（按计划推进）、人际秩序（约定被遵守）——这些对 Si 主导者有切实的情感重量。

来源：cognitiveprocesses.com + psychologyjunkie.md + xhs.md

## 与对立功能的本质区别：Si vs Se

| 维度 | Si（内倾感觉） | Se（外倾感觉） |
|------|---------------|---------------|
| 方向 | 向内：经验积累与参照 | 向外：当下现实与即时感知 |
| 感知对象 | 过去的印象、身体记忆、已知参照 | 眼前的物理细节、当下刺激 |
| 时间导向 | 过去→现在（经验指导行动） | 现在（活在当下，即时响应） |
| 对变化的态度 | 需要时间适应，不确定性引发压力 | 快速读取新情境，适应是本能 |
| 对熟悉感的态度 | 熟悉=安全，喜欢惯例 | 熟悉=无聊，喜欢新刺激 |
| 典型口语 | "以前这样做有效" / "具体点" | "先试试再说" / "就这样了" |

**同一场景对比**：临时改变了今天的计划。
- Si 使用者：内心有轻微不适，开始重新规划接下来的时间，想知道具体改到几点、改成什么形式。
- Se 使用者：无所谓，立刻适应新情境，说不定还觉得意外的变化挺有趣。

来源：totypes.com + cognitiveprocesses.com

## 在不同功能栈位置的表现

**主导位（ISTJ / ISFJ）**：Si 是认知的第一语言，本人可能不会意识到自己在"对照经验"——对他们来说这就是正常的思考方式。ISTJ 用 Te 把 Si 的经验库转化为高效执行系统；ISFJ 用 Fe 把 Si 的细节关注转化为对他人的照顾和连接。

**辅助位（ESTJ / ESFJ）**：有意识地用 Si 为主导功能提供稳定参照。ESTJ 用 Si 的经验数据支撑 Te 的决策；ESFJ 用 Si 记住每个人的喜好和历史来支撑 Fe 的照顾。

**第三位（INTP / INFP）**：偶尔调用，以"曾经发生过什么"为参照给当下决策加一点稳定性。不稳定，使用过久会感到疲惫；但在 Si 成熟后，能让 INTP/INFP 的生活变得更有秩序和可持续。

**劣势位（ENTP / ENFP）**：平时被压抑，压力下爆发。表现为对过去错误的反复执着（rumination）、完美主义式的细节焦虑，或对熟悉感的突然强烈渴望——与其平时追求新奇和可能性的主导功能完全矛盾。

来源：cognitiveprocesses.com + psychologyjunkie.md + zhihu.md

## 与其他功能的组合效应

**Si + Te（ISTJ）**：经验积累 + 高效执行。Si 提供"什么有效"的历史参照，Te 把它转化为标准化流程推进。沟通直接、事实导向，问「具体点」「马上是多久」，是对不确定性最简洁的解决方式。

**Si + Fe（ISFJ）**：经验参照 + 人际照顾。Si 记住每个人的偏好和细节，Fe 把这些记忆转化为对关系的实际维护。「超满计划」「提前到达」「主动察觉受委屈」——都是 Si+Fe 的自然输出。

**Te + Si（ESTJ）**：目标推进 + 稳定参照。Te 是主导，Si 提供「以前这样做有效」的稳定经验支撑，让决策更踏实。

**Fe + Si（ESFJ）**：人际调音台 + 细节记忆。Fe 读取当下情绪，Si 记住每个人的具体情况，两者结合让 ESFJ 成为最能记住你说过的话、最不会让你觉得"我只是个陌生人"的类型。

## 在圆桌对话中的行为模式

- **扮演的角色**：稳定锚/历史证人。「上次我们说的那个……」「以前有一个类似的情况是……」——Si 主导者是讨论中的历史参照库。
- **激活话题**：具体的过去经历、怎么做过有效、安全稳定的路径、「这样做有先例吗」。
- **沉默的情况**：话题太抽象或太假设性；讨论内容和自己的经验库没有交集；氛围太混乱，需要先梳理清楚。
- **发言爆发的情况**：有人忽视了已有的、有效的经验；有人没有遵守约定；有人说"随便"而 Si 知道随便在这件事上会出问题。
- **被集体否定时**：不会轻易放弃历史经验的支撑，但也不会强力争辩——更可能沉默，然后默默继续自己认为可靠的方式。
- **容易产生张力的功能**：Ne（Ne 总想打开新可能，Si 想先用已有的方案）；Se（Se 活在当下，Si 活在过去经验里）。

来源：xhs.md + typemyvibe.md + zhihu-community.md

## 在对话中的具体表现

- **说话节奏**：ISTJ 版本直接、密度高，不做无用铺垫；ISFJ 版本更柔和，带着关心。共同点：用词具体，不模糊，有历史感。
- **句式偏好**：「马上是多久？」「具体点」「以前这样是可以的」「我需要时间考虑一下」；提醒细节、追问精度、以经验为基础。
- **典型行为**：旅行前一天把所有细节确认一遍；帮人做事会记住上次做的方式是否有效；冷场时第一个（ISFJ）或最后一个（ISTJ）开口。
- **压力下的变化**：ISTJ 在极限压力下开始「自我解离」，成为自己描述的「冷漠机器人」；ISFJ 在「付出过多」后情绪枯竭，需要被主动发现。
- **绝对不会说的话**："不用记什么具体的，到时候看着办就行"；"反正计划赶不上变化，就不做计划了"。

来源：xhs.md + typemyvibe.md
