## 主体（按主题）

### 通用：MBTI 官方总览与类型动力学

- 来源 URL：
  - https://www.myersbriggs.org/my-mbti-personality-type/myers-briggs-overview/
  - https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-overview/
  - https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-processes/
- 证据：
  - 官方总览页把 MBTI 定义成一种帮助人理解“能量来源、信息获取、决策方式、生活组织偏好”的框架，用于提升自我认知、沟通、团队协作和发展
  - 官方站明确区分四个偏好维度与 `type dynamics`：四字母代码只是入口，更深入的差异来自各类型在心理过程上的位次顺序
  - `type dynamics overview` 页把每个类型都解释成四个 process 的有序组合：dominant、auxiliary、tertiary、inferior；四者共同塑造人格的稳定模式
  - 官方站对 dominant / auxiliary 的关系写得很清楚：dominant 是最自然、最常用的主过程；auxiliary 既提供平衡，也帮助人格与外部世界建立更成熟的互动
  - tertiary 被写成较晚发展、早期较不成熟但能带来乐趣与弹性的位置；inferior 则是最不熟悉、最容易让人感到笨拙，也最容易在压力下被激活的位置
  - `type dynamics processes` 页把 16 型按主导过程归成 8 组，说明官方站默认认知功能是区分类型的基础层：例如 INTJ/INFJ 共享 dominant Ni，但 auxiliary 分别是 Te 与 Fe
  - 这也提供了 B12 的核心框架：相邻类型之所以容易混淆，往往不是因为字母接近，而是因为共享某个高位过程、但支持过程不同
- 覆盖问题：A1, A2, A5, A6, A7, B2, B4, B12

### 官方 16 型功能位次总表

- 来源 URL：
  - https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-processes/
- 证据：
  - 官方 process 页把 16 型的四位功能顺序按组展开，可整理成完整总表：
  - INTJ：Ni / Te / Fi / Se
  - INFJ：Ni / Fe / Ti / Se
  - ENTJ：Te / Ni / Se / Fi
  - ENFJ：Fe / Ni / Se / Ti
  - INTP：Ti / Ne / Si / Fe
  - INFP：Fi / Ne / Si / Te
  - ENTP：Ne / Ti / Fe / Si
  - ENFP：Ne / Fi / Te / Si
  - ISTJ：Si / Te / Fi / Ne
  - ISFJ：Si / Fe / Ti / Ne
  - ESTJ：Te / Si / Ne / Fi
  - ESFJ：Fe / Si / Ne / Ti
  - ISTP：Ti / Se / Ni / Fe
  - ISFP：Fi / Se / Ni / Te
  - ESTP：Se / Ti / Fe / Ni
  - ESFP：Se / Fi / Te / Ni
  - 官方页还按 dominant process 分组展示这些类型，因此对 A6 和 B12 很有帮助：共享同一 dominant 的两型通常最容易在表层被归为“相似”，真正分化点在 auxiliary
- 覆盖问题：A5, A6, B12

### 通用：类型发展与压力

- 来源 URL：
  - https://www.myersbriggs.org/unique-features-of-myers-briggs/type-development/
- 证据：
  - 官方 `type development` 页把人格发展理解为：随着年龄与经验增长，人会逐步更有意识地使用 top four processes，而不是只靠 dominant 自动驾驶
  - 该页特别强调 inferior process 的两面性：一方面最不熟悉，容易让人感到脆弱；另一方面也是发展和完整性的关键入口
  - 关于压力，官方页明确给出一条重要原则：人在高压下更容易失去平常的平衡，转而以不成熟方式使用 inferior process，因此表现会“看起来不像平常的自己”
  - 官方站还指出，发展不是把所有功能练到一样强，而是提升对不同 process 的识别、尊重和有意识使用，从而减少失衡与投射
  - 这页对 A11/B8 很重要，因为它把 stress reaction 写成“失衡激活低位功能”，而不是单纯情绪波动
- 覆盖问题：A2, A5, A11, B8

### 通用：关系与学习场景中的类型差异

- 来源 URL：
  - https://www.myersbriggs.org/using-type-as-a-tool-for-personal-growth/html/relationships/
  - https://www.myersbriggs.org/using-type-as-a-tool-for-personal-growth/html/learning-styles/
- 证据：
  - `relationships` 页把 MBTI 用在亲密关系、家庭与沟通上，核心结论是：类型差异本身不是问题，误把差异当作恶意、能力缺陷或不在乎，才更容易制造冲突
  - 官方页强调类型帮助人理解：有人更需要先独自处理再表达，有人更需要边聊边想；有人更看重原则一致，有人更先看关系影响
  - 这类差异直接映射到 B6/B11：冲突里常见的摩擦，不一定来自价值观冲突，而是来自不同 process / preference 的沟通路径不同
  - `learning styles` 页把类型差异迁移到学习场景：有人偏好结构、步骤和已知方法；有人偏好概念、可能性和开放探索；有人先靠动手和体验；有人先靠阅读和抽象整合
  - 这些内容虽然不是专门的“说话风格报告”，但足以支持 B3/B7/B9 的一部分：不同类型在什么场景下更投入、怎么吸收信息、是否偏好互动式讨论，官方页都有明确倾向性描述
- 覆盖问题：A8, A9, B3, B6, B7, B9, B11

### 官方 16 型摘要

- 来源 URL：
  - https://www.myersbriggs.org/my-mbti-personality-type/take-the-mbti-instrument/16-mbti-types/
- 证据：
  - ISTJ：官方摘要强调责任感、可靠性、务实与对标准/承诺的坚持
  - ISFJ：强调体贴、忠诚、照顾他人和维护稳定关系
  - INFJ：强调洞察、理想、关注意义与对他人成长的投入
  - INTJ：强调战略性、独立性、长期规划与系统思维
  - ISTP：强调冷静分析、灵活应对、实际问题求解与动手能力
  - ISFP：强调温和、审美、当下体验与按价值行事
  - INFP：强调理想、真诚、价值感和对可能性的关注
  - INTP：强调好奇、理论分析、概念建模和独立思考
  - ESTP：强调行动、现实感、现场判断和快速应变
  - ESFP：强调热情、表现力、关系活力和体验导向
  - ENFP：强调创意、热忱、对人和新想法的兴趣
  - ENTP：强调机智、探索、辩证思考和新颖可能性
  - ESTJ：强调组织、执行、规则、效率与担当
  - ESFJ：强调合作、照顾、社交责任感和支持他人
  - ENFJ：强调鼓舞、引导、关系洞察与带动成长
  - ENTJ：强调领导、决断、战略推进与组织资源
- 覆盖问题：A3, B1, B2, B5, B12

## 交叉验证提示

- `myersbriggs.org` 是官方站，最适合拿来做 `type dynamics`、功能位次、类型发展和官方类型摘要的基线来源；它的语气明显比 jobcannon / psychologyjunkie 更保守、更概括。
- 官方站公开可访问的内容更偏“教育说明页”，而不是深入举例页，因此对 A4、A10、B10、B11 的具体可用度弱于一些民间深度站。
- 官方站在 `relationships` / `learning styles` 页里强调“差异不是问题，误读差异才是问题”，这类 framing 很官方；后续若与更尖锐的冲突风格来源冲突，可标注为“官方表达更温和、抽象”。

## 失败/盲区记录

- 来源清单中提到的 **Myers-Briggs Official Conflict Style Report**（TJ / TP / FJ / FP 四分法）本轮未找到公开可访问的 `myersbriggs.org` 页面，站内公开搜索结果也未能定位到对应 report 页面；因此 B11 只能用 `relationships` 页做部分覆盖。
- 官方站没有提供可直接引用的 typed dialogue / quote examples，因此 A10、B10 仍需其他站点补。
- 官方站没有公开展开 8 个认知功能的逐功能百科页，本轮 A1-A4 主要来自 `type dynamics` 与总览页的概括解释，不适合作为认知功能细节的唯一来源。
