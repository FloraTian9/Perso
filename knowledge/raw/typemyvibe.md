### 通用页证据

#### 通用：MBTI guide 的基本立场

- 来源 URL：
  - https://typemyvibe.ai/blog/mbti-guide
- 证据：
  - `TypeMyVibe` 把 MBTI 解释成基于四组二分法的 16 型框架，但同时强调真正更底层的基础是 `cognitive functions`
  - 这篇 guide 的最大特点不是重复问卷逻辑，而是反复强调：他们通过 `chat history / thousands of messages` 来看自然语言里的偏好痕迹，而不是依赖自评
  - 页面明确把四组二分法翻成沟通行为线索：
    - `E/I` 对应高频外放表达 vs 深思后表达
    - `S/N` 对应细节、例子、流程 vs 概念、可能性、全局
    - `T/F` 对应逻辑论证、 critique、analysis vs values language、情绪与关系意识
    - `J/P` 对应结构、计划、 closure vs 灵活、开放、边走边看
  - 站点还明确说每种类型都有一套 8 功能背景，只是前四位最主导；因此类型页里虽然主要写前四功能，但方法论上承认 8 功能完整背景
- 覆盖问题：A1, A2, A5, B3, B4

#### 通用：认知功能 guide 的站点特色

- 来源 URL：
  - https://typemyvibe.ai/blog/mbti-cognitive-functions
- 证据：
  - 这页把 8 功能直接翻成 `conversation-level` 语言，而不是停留在抽象定义
  - 页面给出的功能抓手非常适合后续 prompt：
    - `Ti` = 内部逻辑、质疑假设、追求定义精确，典型口吻是纠正、澄清、追问结构是否成立
    - `Te` = 外部结构、目标推进、效率与 owner 明确，典型口吻是计划、分工、 deadline、结果导向
    - `Fi` = 内部价值、 authenticity、边界和信念，典型口吻是“这不符合我相信的东西”
    - `Fe` = 外部和谐、照顾他人体验、读气氛和 social smoothing，典型口吻是“大家是否都被照顾到了”
    - `Si` = 记忆、已验证经验、稳定参照和习惯，典型口吻是“上次怎么做的”“什么已经有效”
    - `Se` = 当下体验、现场反应、感官现实和行动感，典型口吻是“现在就做”“看这个”
    - `Ni` = 内部图景、趋势、 underlying pattern 和 long arc，典型口吻是“我感觉事情会往这个方向走”
    - `Ne` = 外部可能性、联想、脑洞和多方案并行，典型口吻是“what if / 还有另一种角度”
  - 页面还给出一个 `ENTP` 的功能栈示例，说明他们会根据聊天语言中的 `Ne-Ti-Fe-Si` 线索去判断一个人为什么像 ENTP，而不是只看四字母表象
- 覆盖问题：A1, A2, A3, A4, A9, A10, B3, B4, B9

#### 通用：TypeMyVibe 的类型页模板

- 来源 URL：
  - 各类型页
- 证据：
  - 16 型页面结构高度统一，通常都包含：`一句话定位`、`4 功能栈`、`communication style`、`texting / professional communication`、`example message patterns`、`strengths`、`weaknesses`、`career paths`、`relationships & compatibility`、`growth tips`、`How TypeMyVibe Identifies X`
  - 这意味着本站最大的价值不是纯理论，而是把人格写成可直接观察的 `聊天模式`
  - 每一页都会给出 2-3 段该类型的示范消息，以及 5-6 条 `chat analysis markers`，对 `A10/B10` 和后续 prompt 极其有用
  - 站点对配对/兼容型也有一套固定写法，但更偏内容运营与人格叙事，不应直接当作科学兼容结论
- 覆盖问题：A9, A10, B9, B10, B12

### INTJ

- 来源 URL：
  - https://typemyvibe.ai/blog/mbti-types/intj
- 功能栈：
  - Dominant: Ni / Auxiliary: Te / Tertiary: Fi / Inferior: Se
- 证据：
  - 页面把 `INTJ` 写成 `The Architect`，核心气质是战略、模式识别、系统化和长期视角，像一直在脑内下多步棋的人
  - 其沟通风格被明确写成 `Strategic Communicator`：消息简短、密度高、常有长停顿、少 emoji、会直接追问关键信息，职业场景中喜欢结构化表达和提前回应反对意见
  - 示例消息模式非常具体：规划时会拿出多方案并说明为什么 `Option B` 最优；反对别人时会直接指出“fundamental flaw”与长期技术债；解释问题时常用框架或复杂类比
  - 页面给出的优势集中在 `战略视野 + systems thinking`；盲点集中在 `dismissive of emotions`、`perfectionism paralysis`、对慢理解者缺乏耐心、以及低位 Se 带来的社交/现场信息遗漏
  - `TypeMyVibe` 识别 INTJ 的聊天标记包括：pattern/framework/root cause 语言、持续的 long-term framing、优化和去冗余冲动、很少社交寒暄、以及长时间沉默后给出高整合度回复
- 覆盖问题：A2, A3, A5, A8, A9, A10, B1, B2, B3, B4, B9, B10, B11

### INTP

- 来源 URL：
  - https://typemyvibe.ai/blog/mbti-types/intp
- 功能栈：
  - Dominant: Ti / Auxiliary: Ne / Tertiary: Si / Inferior: Fe
- 证据：
  - 页面把 `INTP` 写成 `The Logician`，核心是内部逻辑精确、抽象系统建构和 endless theoretical exploration
  - 沟通风格被写成 `Theoretical Debater`：特别在意措辞和定义精度，容易不断补限定条件、跳进理论 rabbit holes，也经常在很长沉默后突然发来一大段深度推演
  - 示例消息模式中，解释问题时会不断加条件和 edge case；争论时会花很长篇幅澄清概念差别；甚至会在凌晨突然补一条“我刚意识到三周前那个讨论还可以用 modal logic 重算”
  - 页面把其强项写成 `logical precision` 和 `conceptual innovation`，盲点则是 `analysis paralysis`、社交迟钝、为理论牺牲现实事务，以及为了智识乐趣去 argue positions they don't even hold
  - 识别标记包括：technically/precisely/actually 语言、理论切线、抓小逻辑错、层层限定、devil's advocate 式争论，以及长沉默后突然冒出的高密度深思消息
- 覆盖问题：A2, A3, A5, A8, A9, A10, B1, B3, B4, B9, B10, B11

### ENTJ

  - https://typemyvibe.ai/blog/mbti-types/entj
- 功能栈：
  - Dominant: Te / Auxiliary: Ni / Tertiary: Se / Inferior: Fi
- 证据：
  - 页面把 `ENTJ` 写成 `The Commander`，核心是外部组织、战略推进、资源调度和高目标压强
  - 沟通风格是 `Executive Communicator`：直接、下指令、行动导向、容忍不了含糊，工作沟通会默认清晰目标、owner、metrics 和 timeline
  - 示例消息模式里，领导场景会直接分配 Team A / Team B / deadline / escalation；解决问题时会迅速重构 workflow；战略场景里会自然把话题拉到 18 个月后的市场位置
  - 页面把其优势写成 `strategic leadership` 与 `decisive execution`，盲点写成 `emotional blindness`、对低水平执行极不耐烦、强控制欲和工作狂倾向
  - 聊天识别标记包括：命令式动词、strategic framing、ROI/metrics/optimization 语言、快速决策、天然领导语气和持续的结果导向

  - 示例消息模式特别适合 prompt：brainstorm 时会不断翻案和加新变量；debate 时会先反驳，再主动补上自己论证的 counterargument；random insight 会突然跨领域连线
  - 页面把其优势写成 `innovative thinking` 和 `intellectual agility`，盲点则是跟进差、太爱争、忽略 routine/detail、以及对无聊的强不耐受
  - 识别标记包括：what if / another angle 语言、喜欢 intellectual sparring、信息 burst、多 tangent、用 Ti 挑逻辑错，以及高能量带动别人兴奋

  - Dominant: Ni / Auxiliary: Fe / Tertiary: Ti / Inferior: Se

  - 识别标记包括：deeper meaning / beneath the surface 语言、深层提问、理想主义愿景、 carefully considered replies、quality over quantity 的连接方式

  - Dominant: Ne / Auxiliary: Fi / Tertiary: Te / Inferior: Si

  - 标记包括：大量 excited punctuation、点子连跳、对人和创意都表现出很高热情、重 authenticity、对琐碎组织细节不耐烦

## 交叉验证提示

- `typemyvibe` 最大的价值不是理论原创，而是把类型差异翻译成 `chat-language markers`、`example message patterns` 和 `how this type texts/debates/works`。
- 它对 `A9/A10/B9/B10/B11` 尤其强，适合后续写 prompt 的口吻、节奏和冲突体感。
- 它对 `A1-A4` 也有帮助，但定义明显更内容运营化、面向大众传播；如果后续涉及功能理论争议，应优先回到 `typeinmind / personalityjunkie / personalityhacker / totypes`。
- 站点反复强调“从聊天记录而不是自评问卷识别类型”，因此它更像 `behavioral expression layer`，不是最上游类型学源头。

## 失败/盲区记录

- 本轮成功抓到 16 型页面和 2 个通用页面正文，但站点内容主要聚焦前四功能，没有系统展开 shadow functions，因此 A11 只能部分覆盖。
- 兼容型、名人列表、职业推荐等板块更偏内容运营与读者体验，后续整合时不宜与功能理论同权。
- 本站没有专门的“topic reaction”或“serious vs light topic”分栏，因此 B7 仍需其他站点补。
