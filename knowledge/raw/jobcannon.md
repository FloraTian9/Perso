### 通用：八功能定义

- 来源 URL：
  - https://jobcannon.io/blog/mbti-cognitive-functions-guide
  - https://jobcannon.io/blog/mbti-cognitive-functions-complete-guide
- 证据：
  - JobCannon 明确把认知功能定义为“比 4 字母更深一层的系统”，强调不同类型的差异来自八个心理过程的排序，而不只是 I/E、N/S、T/F、J/P 标签
  - **Te** 被定义为外部组织、效率、可衡量结果与系统搭建；主导类型为 ENTJ / ESTJ，天然会看见低效并想立刻修正
  - **Ti** 被定义为内部逻辑精度、框架一致性与原理拆解；主导类型为 INTP / ISTP，更在意论证是否真的正确，而不只是是否有用
  - **Fe** 被定义为对群体情绪氛围的敏感、关系协调与社会价值；主导类型为 ENFJ / ESFJ，会先读取环境中的人际动态
  - **Fi** 被定义为内部价值、真实性与个人伦理；主导类型为 INFP / ISFP，会先判断一件事是否与内在信念对齐
  - **Ne** 被定义为向外发散的可能性生成与跨领域联想；主导类型为 ENTP / ENFP，不断看到替代解释、未探索组合与新方向
  - **Ni** 被定义为向内收束的模式综合与未来轨迹洞察；主导类型为 INTJ / INFJ，会从大量信息中收拢出强烈、聚焦的 insight
  - **Se** 被定义为对当下物理现实的直接参与和即时感知；主导类型为 ESTP / ESFP，更擅长处理具体、快速、行动导向的场景
  - **Si** 被定义为内部化的经验记忆、过去经验对照与对已验证方法的偏好；主导类型为 ISTJ / ISFJ，会先联想到“以前是怎么做的”
- 覆盖问题：A1, A2, A3, A4, A6

### 通用：功能栈层级与 16 型总表

- 来源 URL：
  - https://jobcannon.io/blog/mbti-cognitive-functions-guide
  - https://jobcannon.io/blog/cognitive-function-stacks-mbti
  - https://jobcannon.io/blog/mbti-cognitive-functions-complete-guide
- 证据：
  - 本站把四功能栈解释为：dominant = 最自然、最自动、最强的主镜头；auxiliary = 支撑并平衡 dominant 的第二功能；tertiary = 较晚成熟、早期常显得幼稚但成熟后会增加厚度；inferior = 最弱、最容易在压力下失控、同时也是成长入口的功能
  - 站点明确列出 16 型功能栈：INTJ Ni-Te-Fi-Se，INTP Ti-Ne-Si-Fe，ENTJ Te-Ni-Se-Fi，ENTP Ne-Ti-Fe-Si，INFJ Ni-Fe-Ti-Se，INFP Fi-Ne-Si-Te，ENFJ Fe-Ni-Se-Ti，ENFP Ne-Fi-Te-Si，ISTJ Si-Te-Fi-Ne，ISFJ Si-Fe-Ti-Ne，ESTJ Te-Si-Ne-Fi，ESFJ Fe-Si-Ne-Ti，ISTP Ti-Se-Ni-Fe，ISFP Fi-Se-Ni-Te，ESTP Se-Ti-Fe-Ni，ESFP Se-Fi-Te-Ni
  - 站点强调 dominant / auxiliary 会自然发展，而 tertiary / inferior 更需要时间与刻意练习；因此同一类型的人在不同年龄层会呈现不同成熟度
  - 站点还把“同字母但不同功能顺序”当作一个核心纠偏点，例如 INTJ 与 INTP 虽共享 I/N/T 三个字母，但一个是 Ni-Te，一个是 Ti-Ne，内在认知方向完全不同
- 覆盖问题：A5, A6, B3, B12

### 通用：主导功能在实践中的第一反应

- 来源 URL：
  - https://jobcannon.io/blog/cognitive-function-stacks-mbti
- 证据：
  - **主导 Te**（ENTJ / ESTJ）：对情境的第一反应是立刻组织、排布、修复低效并推进执行
  - **主导 Ti**（INTP / ISTP）：第一反应是先建立或调用一个准确的内部逻辑框架，优先解决不一致
  - **主导 Fe**（ENFJ / ESFJ）：第一反应是先读取情绪气候和人际状态，再围绕群体和谐调整表达与动作
  - **主导 Fi**（INFP / ISFP）：第一反应是先问自己这件事在道德或价值上“对不对”
  - **主导 Ne**（ENTP / ENFP）：第一反应是迅速生成多种可能性、角度和组合
  - **主导 Ni**（INTJ / INFJ）：第一反应是寻找表象下方的模式或趋势，经常“先知道再解释”
  - **主导 Se**（ESTP / ESFP）：第一反应是完全进入当前现实，优先处理眼前可感知、可操作的东西
  - **主导 Si**（ISTJ / ISFJ）：第一反应是对照过去经验，判断“这像不像以前”“历史上什么方法奏效”
- 覆盖问题：A2, A3, A8, B3

### 通用：发展路径、劣势功能与 shadow

- 来源 URL：
  - https://jobcannon.io/blog/mbti-cognitive-functions-guide
  - https://jobcannon.io/blog/cognitive-function-stacks-mbti
  - https://jobcannon.io/blog/mbti-cognitive-functions-complete-guide
- 证据：
  - 本站把劣势功能称为最值得关注的成长边缘：它平时较不成熟，但在压力下最容易出现“完全不像本人”的行为
  - 对 life-stage 的描述是：20s 更明显发展 dominant，30s 强化 auxiliary，40s tertiary 渐渐成熟，50s+ 才更可能稳定整合 inferior
  - **Ni 主导**（INTJ / INFJ）的 Se grip：会突然沉迷感官细节、即时刺激、暴食/过度锻炼，或失去平时的长期视角，只盯着眼前具体事实
  - **Ne 主导**（ENTP / ENFP）的 Si grip：会变得异常挑剔、怀旧、悲观、执着旧经验，或对轻微身体不适极端敏感
  - **Te 主导**（ENTJ / ESTJ）的 Fi grip：会比平时更情绪化、把事情个人化、表达受伤感，或做出强价值染色的情绪决定
  - **Fe 主导**（ENFJ / ESFJ）的 Ti grip：会变得过度挑错、四处找逻辑漏洞、退出社交去单独思考，并暂时失去平时的人情味
  - 另一篇总览补充了 shadow functions：shadow 是同一八功能在相反态度上的“无意识背面”，极端压力下会让人表现出陌生、异化的一面；站点举 INTJ 为例，称其 shadow stack 为 Ne-Ti-Fe-Si，严重受压时可能从聚焦式 Ni 变成散乱、偏执的可能性联想
- 覆盖问题：A5, A11, B8

### 代表类型页主题：INFJ

- 来源 URL：
  - https://jobcannon.io/blog/infj-personality-guide
- 证据：
  - INFJ 被描述为“极其私密但又真正以他人为导向”的类型：Ni 在内部综合模式，Fe 把洞察翻译成对他人有帮助的表达
  - Ni 被写成一种“just knowing”式的模式综合，常先感到强烈确定感，再慢慢补上可解释的推理；优势是远景感，风险是对自己直觉过度自信
  - Fe 让 INFJ 真正吸收他人情绪并想促进他人福祉，因此很适合咨询、辅导、倡导等需要深度理解人的场景
  - Ti 是内藏的分析能力，让 INFJ 在需要时也能做严谨的逻辑拆解，只是这部分不总在外表上高调展示
  - Inferior Se 在压力下可表现为异常敏感、冲动、短时享乐导向，如吃、买、沉迷感官刺激来“找回地面感”
  - 关系层面，站点强调 INFJ 需要深度对话、诚实与成长感；反复触碰底线后会出现典型的 “door slam”
- 覆盖问题：A3, A5, A11, B1, B2, B3, B8

### 代表类型页主题：INTJ

- 来源 URL：
  - https://jobcannon.io/blog/intj-personality-guide
- 证据：
  - INTJ 被写成“战略愿景 + 系统执行”的组合体：Ni 提供远期图景，Te 负责把图景变成可实施的结构
  - 站点强调 Ni 对 INTJ 来说像持续运作的预测引擎，会给出强烈确定感；优势是经常先看到趋势，风险是错了也不容易立刻承认
  - Te 带来直接、讲效率、建流程、定标准的外在风格，因此 INTJ 的核心不是只有洞察，还有把洞察落成制度或方案的能力
  - 第三位 Fi 让 INTJ 拥有很深但很私密的价值观，也解释了他们为什么会拒绝没有道理、只凭权威压下来的命令
  - Inferior Se 被描述为最脆弱的环节：平时可能忽略当下环境和身体需要，高压下则可能突然过度感官化、暴食、饮酒、寻求刺激，或因过度沉浸脑内世界而显得笨拙
  - 关系层面，INTJ 更像通过忠诚、行动、记住重要细节来表达爱，而不是高频情绪表白
- 覆盖问题：A3, A5, A11, B1, B2, B3, B4, B8

### 代表类型页主题：ENFP

- 来源 URL：
  - https://jobcannon.io/blog/mbti-enfp-career-guide
- 证据：
  - ENFP 被写成由 Ne 主导、Fi 支撑的类型：Ne 持续生成连接、点子和替代路径，Fi 提供个人价值与对人性的深层共鸣
  - 站点把 ENFP 的优点写得很“外放”：热情、创意、与人快速建立连接、把复杂想法讲得易懂、适应新环境快
  - 弱点也被写得很明确：容易分散、细节不稳、难以长期完成自己开启的项目；这与其低位 Si / 执行稳定性压力一致
  - 工作偏好上，ENFP 适合变化多、自由度高、有人味、有正向使命感的环境；重流程、重例行、重文书的岗位会持续消耗
  - 从说话和对话风格上看，站点把 ENFP 描述成擅长用热情和可理解的方式表达复杂想法的人
- 覆盖问题：A2, A3, A8, A9, B1, B2, B5, B9

### 代表类型页主题：INFP

- 来源 URL：
  - https://jobcannon.io/blog/infp-personality-guide
- 证据：
  - INFP 被写成“安静但内部极其复杂”的理想主义者：由 Fi 主导、Ne 支撑，强烈依赖私人价值系统而不是外部规范做判断
  - 站点强调他们的优势不只是温柔，而是深度真诚、强共情、创造力和对原则的不退让
  - 弱点集中在 inferior Te：行政执行、deadline、结构化推进和把理想落地会持续吃力；长期受压时会变得冷、挑错、过度逻辑化
  - 关系层面，INFP 需要能接住其内在深度的伴侣；若作品或价值被批评，常会体验为“整个人被否定”
- 覆盖问题：A3, A5, A11, B1, B2, B8

### 代表类型页主题：INTP

- 来源 URL：
  - https://jobcannon.io/blog/intp-personality-career-guide
- 证据：
  - INTP 被写成“想理解底层系统而不是只拿答案”的分析型人格；Ti 是核心驱动，Ne 负责持续提供新思路和跨领域连接
  - 站点特别强调他们不接受外部规则的表面权威，必须先通过自己的逻辑系统验证
  - Si 给了他们对重要数据和事实的细节记忆，也解释了其私生活中对某些熟悉例行的偏好
  - Inferior Fe 被直接写成 Achilles heel：压力下可能异常情绪化，或完全社交关机
- 覆盖问题：A2, A3, A5, A11, B1, B3, B4, B8

### 代表类型页主题：ISFP

- 来源 URL：
  - https://jobcannon.io/blog/isfp-personality-career-guide
- 证据：
  - ISFP 被写成“安静艺术家”：Fi 提供非常私密但强烈的价值与情感深度，Se 让这种深度通过审美、手作、创作和感官体验落地
  - 站点强调 ISFP 的优势在于自然审美、真诚同理和不做作的情感表达，不会高调表演深度，但深度真实存在
  - 他们更适合有创作自由、能表达个人风格的环境；一旦工作违背价值或太机械，会明显失去生命力
  - 搜索对比页还把 ISFP 概括为“living fully in the moment and expressing authentic feeling”，与 INFJ 的道德洞察形成可区分对照
- 覆盖问题：A2, A3, A8, B1, B2, B9

### 代表类型页主题：ISTP

- 来源 URL：
  - https://jobcannon.io/blog/istp-career-guide
  - https://jobcannon.io/type-in-relationships/istp
- 证据：
  - ISTP 被写成 Ti-Se 的“hands-on problem solver”：他们不是为理论而理论，而是想理解现实系统怎么运作、哪里坏了、怎么修
  - 站点明确区分 ISTP 与 INTP：二者都用 Ti，但 ISTP 的分析是落在物理系统、工具、机制和实时问题上的
  - 第三位 Ni 提供偶发的长期模式洞察，但不是持续主导；其外在风格更偏独立、低废话、结果导向
  - 关系页补充说 ISTP 的爱意常通过 shared experiences、physical presence、practical support 表达；冲突中倾向先 withdraw 再处理
- 覆盖问题：A3, A5, A8, A9, B1, B3, B9, B11

### 代表类型页主题：ISFJ

- 来源 URL：
  - https://jobcannon.io/blog/isfj-personality-career-guide
- 证据：
  - ISFJ 被写成“quiet pillars of every community”：Si 让他们记住细节、流程和承诺，Fe 让这些细节天然指向照顾他人和维系和谐
  - 站点反复强调其优势是可靠、耐心、细致、责任感强，而且会记住别人忽略的小事
  - 适合帮助他人且有结构稳定性的职业环境；这与其 Si-Fe 组合高度一致
  - 成长难点是边界、把批评与自我价值分离、减少完美主义，以及别总把别人放在自己前面
- 覆盖问题：A2, A3, A5, B1, B2, B8

### 代表类型页主题：ISTJ

- 来源 URL：
  - https://jobcannon.io/blog/istj-personality-guide
- 证据：
  - ISTJ 被写成“reliable engines of institutions”：不是因为爱表演可靠，而是把守承诺、守标准当成深层价值
  - 站点把其 archetype 定义为 Inspector / Logistician，强调他们维持系统运作、确保标准不滑坡、在别人松动时继续扛住责任
  - 这页还把 ISTJ 明确放在“最常见类型”语境中，强调其不追求花哨识别度，但组织与家庭离不开这种持续、稳定、低戏剧性的执行力
- 覆盖问题：A3, B1, B2, B5

### 代表类型页主题：ENFJ

- 来源 URL：
  - https://jobcannon.io/ua/personality-types/enfj/careers
  - https://jobcannon.io/compatibility/mbti/infj-enfj
- 证据：
  - ENFJ 被写成最 people-oriented 的类型之一，最被“理解人、帮助人发展、建设文化与社区”这类工作所激活
  - 站点把其核心优势总结为 inspiring growth and building community，典型适配是教练、L&D、HR、社区运营、客户成功等高人际密度角色
  - 远程工作部分补充了 B8：ENFJ 的风险不是冷淡，而是对每个人投入过量关注导致 burnout
  - 兼容性页还补了一条功能层信息：INFJ 与 ENFJ 共享四个功能但顺序互补，说明该站默认把 ENFJ 看成 Fe-Ni-Se-Ti 结构

### 类型对比与同字母误判

- 来源 URL：
  - https://jobcannon.io/blog/cognitive-function-stacks-mbti
  - https://jobcannon.io/blog/infj-vs-intj-personality
  - https://jobcannon.io/blog/entj-vs-intj-comparison
- 证据：
  - JobCannon 用 INFJ vs INFP 举例说明“共享 3 个字母不代表共享相同认知过程”：INFJ 是 Ni-Fe-Ti-Se，INFP 是 Fi-Ne-Si-Te，外在都可能显得理想主义，但内部运作截然不同
  - INFJ vs INTJ 的核心差异被写成：两者都由 Ni 主导，但 INFJ 的 Ni 服务于理解人和促进成长，INTJ 的 Ni 服务于理解系统和优化结构
  - 在社交呈现上，INFJ 因 Fe 更容易显得温暖、会调节语气和氛围；INTJ 因 Te 更直接、更少为情绪冲击做缓冲，因此容易被读成冷或硬
  - 在压力下，INFJ 文中写为 inferior Se 失控：冲动、感官过度、短视；这与其主页面一致
  - ENTJ vs INTJ 则被解释为相同的 Ni/Te 组合顺序不同：ENTJ 是 Te 先行，先组织外部世界再调用 Ni；INTJ 是 Ni 先行，先形成内部图景再用 Te 实施
  - 工作和对话风格上，ENTJ 更外放、高频、公开辩论、会在会议中直接带头；INTJ 更偏提前思考、精准发言、厌恶无意义会议、通常先私下整合观点再发声
  - 冲突上，两者都直接，但 ENTJ 更享受高强度辩论，INTJ 更倾向尽快解决而不是长时间拉扯
- 覆盖问题：A4, A7, A8, A9, B4, B6, B9, B11, B12

## 交叉验证提示

- **站内自相矛盾**：`infj-vs-intj-personality` 把“受压 INTJ”写成会启动 “inferior Extraverted Feeling”，但同站 `intj-personality-guide` 与功能栈总表都明确 INTJ 的劣势是 Se、而非 Fe。后续整理知识库时，应以其主类型页和功能栈页为准，并把该对比页标记为站内冲突来源。
- 本站整体偏“现代职场 / 生涯发展”语境，很多描述会落在 career fit、work style、leadership 语言上；后续若与更经典荣格或 Beebe 风格来源不同，应注明 JobCannon 偏应用场景化解释。

## 失败/盲区记录

- 本站没有抓到可直接复用的 typed dialogue / quoted dialogue 页面，因此 A10、B10 仍需其他站点补。
- 本站对劣势功能最具体的是 Ni / Ne / Te / Fe 主导四组；Ti / Fi / Se / Si 主导组的 grip 描述更多依赖类型页和泛化说明，A11 虽可覆盖但细节密度不如 psychologyjunkie。
- 本站 16 型页面深度不均：INFJ / INTJ / INFP / INTP / ISTJ / ISFJ / ISFP / ISTP / ENTJ / ESTJ / ESFP 有相对完整的 blog/career guide，ENFJ / ESFJ / ESTP / ENTP 则更多依赖 career、relationship、result 或 comparison 页面补齐。
- 本站很多文章是 career guide 或 comparison guide，适合补 A5 / A11 / B12，但仍不适合单独作为 16 型完整人格原始库。
