# 认知功能总览

> 本文件是 8 个认知功能的索引与横向对比。每个功能的详细描述见各独立文件。

---

## 什么是认知功能

认知功能（Cognitive Functions）是 Carl Jung 提出的、用于描述人类信息处理方式的理论框架。MBTI 的四字母类型本质上是 8 个认知功能不同排列顺序的简化编码。

每个人的功能栈按「主导 → 辅助 → 第三 → 劣势」排列，前两位是日常惯用的，后两位是相对不成熟或平时被压抑的。

来源：totypes.com + cognitiveprocesses.com + psychologyjunkie.md

## 4 组对立功能

每对对立功能不是强弱之分，而是信息处理方向的根本不同：

### Ni vs Ne
- **Ni**：向内收束，寻找唯一真相；综合矛盾信息，洞察以顿悟形式浮现
- **Ne**：向外发散，发现无数可能；从单一念头看出大量关联，在互动中实时生长
- **核心差异**：Ni 想"这件事终究会走向哪里"；Ne 想"这件事还可以有哪些方向"

### Ti vs Te
- **Ti**：向内精确，内部逻辑自洽；追求"刚刚好的词"和"本质差别"
- **Te**：向外推进，外部结果产出；把想法转化为可追踪的结构、目标和执行
- **核心差异**：Ti 问"这是怎么运作的"；Te 问"谁来做、什么时候完成"

### Fi vs Fe
- **Fi**：向内一致，私密的价值雷达；经常通过行动而非语言表达
- **Fe**：向外调节，外显的人际调音台；实时读取和影响群体情绪
- **核心差异**：Fi 关心"我内心真正相信什么"；Fe 关心"我们在这个关系里都还好吗"

### Si vs Se
- **Si**：向内参照，经验积累为稳定参照库；「以前这样做有效」是重要决策依据
- **Se**：向外感知，活在当下物理现实；「先体验，再感受」，即时响应，迅速适应
- **核心差异**：Si 活在过去经验里；Se 活在当下感官里

来源：totypes.com + cognitiveprocesses.com + zhihu.md

## 功能栈位置说明

### 主导功能（第1位）
最自然、最持续的认知方式。本人可能不会意识到自己在用——对他们来说，这就是"正常思考方式"。压力最大时可能走向过度使用主导功能（主导功能音量开太大）。

### 辅助功能（第2位）
支撑主导功能的落地。通常是主导功能的「对齐轴」：主导是感知功能时，辅助是判断功能，反之亦然；主导是内倾时，辅助是外倾，反之亦然。

### 第三功能（第3位）
不稳定，偶尔冒出来。通常在放松、创意或游戏状态中调用，使用过久会感到疲惫。在青少年期相对脆弱，随年龄增长可以得到发展。

### 劣势功能（第4位）
平时被压抑，是最不熟练的位置。在极端压力下以失控方式爆发，通常表现出与主导功能完全相反的特质——ESTP 的劣势 Ni 会出现宿命化焦虑；INFJ 的劣势 Se 会走向感官沉迷。随年龄增长可以通过主动发展成为成熟的补充。

来源：cognitiveprocesses.com + psychologyjunkie.md

## 4 个 Shadow 功能（第5-8位）

Shadow 功能位于意识和无意识的边界，是自我未活出的、被压抑的一面。在自我工具不够用时或受到威胁时浮现：

| 位置 | 名称 | 触发方式 | 表现 |
|------|------|---------|------|
| 第5位 | Opposing Role | 被挫败、自我受威胁时 | 傲慢地对抗主导功能，以被动攻击或偏执方式出现 |
| 第6位 | Critical Parent | 以贬低、羞辱的方式镜像辅助功能 | 严苛的内部自我批评，缺乏意识的监管 |
| 第7位 | Trickster | 制造混乱和困惑 | 双重束缚、欺骗性、逃避 |
| 第8位 | Demon | 最疏远、最他者化的功能 | 与最大失败和弱点相关，极端压力下破坏性出现 |

来源：psychologyjunkie.md

## 在圆桌对话中识别认知功能的线索

| 功能 | 圆桌识别线索 |
|------|------------|
| Ni | 长时间沉默后给出一针见血的洞察；会把讨论收束到"底层问题是什么" |
| Ne | 最先抛出新话题或新角度；话题会跳；说"wait wait还有——" |
| Ti | 在别人论证中找到逻辑漏洞并精准指出；问"这个词到底是什么意思" |
| Te | 说"谁来负责？时间线是什么？"；在讨论结束时推动到具体行动 |
| Fi | 平时沉默，核心信念被触碰时突然说出意外强烈的话 |
| Fe | 冷场时第一个开口；关注每个人有没有参与进来 |
| Si | 提供"以前这样做"的历史参照；追问"具体点/到底几点" |
| Se | 最活在当下；话题从现场细节展开；行动先于计划 |

## 常见误判线索

- **Ni vs Ne**：Ni 主导者安静、收束、等洞察完整再说；Ne 主导者活跃、发散、边互动边长出想法
- **Ti vs Te**：Ti 追求内部定义精度（"严格来说……"）；Te 追求外部结果（"谁来做"）
- **Fi vs Fe**：Fi 通过行动而非语言表达价值；Fe 主动表达并调节群体情绪
- **Si vs Se**：Si 话题偏向历史经验（"以前……"）；Se 话题偏向当下感受（"你有没有感觉到"）
- **高 N vs 高 S**：N型偏抽象/可能性/模式；S型偏具体/当下/细节
- **高 T vs 高 F**：T型优先评估逻辑合理性；F型优先考虑人际和情感维度
