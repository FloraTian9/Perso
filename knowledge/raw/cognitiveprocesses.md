### 通用：站点理论立场与类型动力学

- 来源 URL：
  - https://www.cognitiveprocesses.com/
  - https://cognitiveprocesses.com/Cognitive-Functions/index.cfm
  - https://www.cognitiveprocesses.com/16Types/16Types.cfm
- 证据：
  - 站点把自己定位为“8 个荣格认知功能”的说明站，明确把 Jung 的 8 个基础心理过程、Myers-Briggs 的 16 型、以及 Linda Berens / Dario Nardi 的 type dynamics 解释连接在一起
  - 站点强调：每个人都能接触全部 8 个过程，但不同类型会形成“可预测的使用模式”；类型差异不只是四字母标签，而是 8 个过程在日常生活中的角色顺序不同
  - `16Types` 总览页把 8 个角色分成两层：前四位是 primary processes，分别是 Leading / Supporting / Relief / Aspirational；后四位是 shadow processes，分别是 Opposing / Critical Parent / Deceiving / Devilish
  - 站点对前四位的解释非常明确：Leading 是最自然、最容易依赖的主过程；Supporting 与之配合；Relief 是放松和回气的出口；Aspirational 是想做好、会驱动成长但也最容易显得不熟练的位置
  - `16Types` 页还直接指出：人会在不同生命阶段逐步发展这些过程；如果对某过程“有能力却没意识到”，会把它视为理所当然；如果“无能又没意识到”，则更容易把它的负面面向投射到别人身上
  - `Cognitive Functions` 首页给了一个粗略比例感：dominant 大约描述 75%，auxiliary 约 15%；这种写法明显是为入门解释服务，方便把“主导/辅助差距很大”这个直觉快速讲清
  - 16 型总览页提供了一张完整的 8 角色总表，是本站最关键的 A5 / A6 / B12 原始证据：
  - ISTJ — Planner Inspector：Si / Te / Fi / Ne / Se / Ti / Fe / Ni
  - ISFJ — Protector Supporter：Si / Fe / Ti / Ne / Se / Fi / Te / Ni
  - INFJ — Foreseer Developer：Ni / Fe / Ti / Se / Ne / Fi / Te / Si
  - INTJ — Conceptualizer Director：Ni / Te / Fi / Se / Ne / Ti / Fe / Si
  - ISTP — Analyzer Operator：Ti / Se / Ni / Fe / Te / Si / Ne / Fi
  - ISFP — Composer Producer：Fi / Se / Ni / Te / Fe / Si / Ne / Ti
  - INFP — Harmonizer Clarifier：Fi / Ne / Si / Te / Fe / Ni / Se / Ti
  - INTP — Designer Theorizer：Ti / Ne / Si / Fe / Te / Ni / Se / Fi
  - ESTP — Promoter Executor：Se / Ti / Fe / Ni / Si / Te / Fi / Ne
  - ESFP — Motivator Presenter：Se / Fi / Te / Ni / Si / Fe / Ti / Ne
  - ENFP — Discoverer Advocate：Ne / Fi / Te / Si / Ni / Fe / Ti / Se
  - ENTP — Explorer Inventor：Ne / Ti / Fe / Si / Ni / Te / Fi / Se
  - ESTJ — Implementor Supervisor：Te / Si / Ne / Fi / Ti / Se / Ni / Fe
  - ESFJ — Facilitator Caretaker：Fe / Si / Ne / Ti / Fi / Se / Ni / Te
  - ENFJ — Envisioner Mentor：Fe / Ni / Se / Ti / Fi / Ne / Si / Te
  - ENTJ — Strategist Mobilizer：Te / Ni / Se / Fi / Ti / Ne / Si / Fe

### 八功能页面证据

#### Se

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Extraverted-Sensing.cfm
- 证据：
  - Se 被定义为“在丰富细节里觉察物理世界”，并且往往会立刻想对经验采取行动、获取即时结果
  - 该过程会主动扫描当下情境中的相关事实和线索，直到当前输入被穷尽或被新的刺激吸走
  - 典型表现包括：跟随当下冲动、享受动作与即时冲击、用身体和环境高度同步、迅速读取情境边界后再决定能走多远
  - 站点给出的关键词明显偏 present-moment immersion、raw data response、physical presence
- 覆盖问题：A1, A2, A3, A4, B3

#### Si

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Introverted-Sensing.cfm
- 证据：
  - Si 被定义为储存信息与经验，再把当前情境与过往相似情境做对照
  - 它不仅回忆事实，也会把与事实相连的感受、身体印象、经验后果一起调出来，因此“像曾经发生过什么”会立刻影响当下判断
  - 典型表现包括：注意细节、依赖历史经验和熟悉流程、从 hindsight 和 lessons learned 里找答案、保护长期可靠和已知可持续的事物
  - 站点还强调 Si 与文化、习俗、延续性有关，不只是“记性好”
- 覆盖问题：A1, A2, A3, A4, B3

#### Ne

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Extraverted-iNtuiting.cfm
- 证据：
  - Ne 被定义为从单一念头或当前互动中看出大量隐藏含义和可能解释，并把不同情境的线索交织起来
  - 站点强调 Ne 的想法经常不是事先整体成形，而是在 here-and-now 的互动里逐步冒出来
  - 典型表现包括：脑中同时容纳多种甚至冲突的解释、热爱 brainstorm、通过 imaginative play 测试场景、在互动中 extemporaneously 塑形局面
  - 这一定义对 A8/A9 很有价值，因为它直接解释了为什么 Ne 主导的人在讨论里常像“边说边长出想法”
- 覆盖问题：A1, A2, A3, A4, A8, A9, B3, B9

#### Ni

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Introverted-iNtuiting.cfm
- 证据：
  - Ni 被定义为综合看似矛盾的东西，从而把理解推进到更深层；典型体验是突然出现的 “Aha / That's it”
  - 站点特别强调 Ni 的 future sense 带有确信感和 imperative quality，像一种“这就是未来走向”的内在命令
  - 它还会借助象征、焦点装置、趋势与征兆来预测或转化情境，并能为复杂概念或普遍性问题生成整合式理解
  - 与 Ne 对照时，Ni 明显更偏整合与收束，Ne 更偏交互中涌现与发散
- 覆盖问题：A1, A2, A3, A4, A8, B3

#### Te

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Extraverted-Thinking.cfm
- 证据：
  - Te 被定义为用外显结构组织环境与想法：做 contingency planning、schedule、quantify、chart、outline，并持续监控效率
  - 站点把 empirical thinking 放在 Te 核心位置：它会依据眼前事实去挑战观点，并希望把他人的思路也整理出清晰顺序
  - 典型表现包括：直接指出缺漏、按目标切分问题、把生活不同部分 compartmentalize，以完成既定任务
  - 这一页对 Ti/Te 对比很有用：Te 更快进入结构化执行和外显逻辑排序
- 覆盖问题：A1, A2, A3, A4, B4

#### Ti

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Introverted-Thinking.cfm
- 证据：
  - Ti 被定义为用内部标准寻找“刚刚好的词”和“本质差别”，把东西拆开看它究竟怎么运作
  - 它会从一般原则推导子原则和分类，并寻找修复系统时“最小代价的杠杆点”
  - 典型表现包括：指出逻辑不一致、细分概念、建立模型来评估观察是否准确、追求 crisp and to-the-point 的表述
  - 站点对 Ti 的描述明显比“只是逻辑”更细，强调的是内部定义精度和结构纯度
- 覆盖问题：A1, A2, A3, A4, B4

#### Fe

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Extraverted-Feeling.cfm
- 证据：
  - Fe 被定义为连接或断开他人、读取显性和隐性需要，并根据群体氛围调整回应
  - 所谓 social graces、礼貌、友善、适宜、一起笑、让人彼此善待，都被站点归到 Fe
  - 典型表现包括：通过 self-disclosure 带动他人开口、主动问对方要什么、把自己拉进共享价值和社会规范，以换取协调与连结
  - 站点也提醒：Fe 强时容易把别人的情绪和自己的情绪搅在一起
- 覆盖问题：A1, A2, A3, A4, A8, A9, B4, B9

#### Fi

- 来源 URL：
  - https://www.cognitiveprocesses.com/Cognitive-Functions/Introverted-Feeling.cfm
- 证据：
  - Fi 被定义为一种持续衡量“什么有价值、什么值得信、什么重要”的内部过滤器，但这些价值常更像图像、气氛、gut reaction，而不是清晰口号
  - 它大多数时间在私下工作，经常通过行动而不是外显语言表达
  - 典型表现包括：发现虚假与不真诚、辨认人或项目的“本质感”、在价值被侵犯时才突然说出“有些话必须说”
  - 这页对 Fi/Fe 区分很关键：Fi 更像私密的价值一致性雷达，Fe 更像外显的人际调音台
- 覆盖问题：A1, A2, A3, A4, A8, A9, B4, B9

### 通用：创造力、沟通与问题解决

- 来源 URL：
  - https://www.cognitiveprocesses.com/usesoftype/
  - https://www.cognitiveprocesses.com/usesoftype/Cognitive-Processes-And-Communication.cfm
  - https://www.cognitiveprocesses.com/usesoftype/Cognitive-Processes-And-Problem-Solving.cfm
  - https://www.cognitiveprocesses.com/usesoftype/cognitive-processes-and-idea-generation.cfm
  - https://www.cognitiveprocesses.com/usesoftype/cognitive-processes-and-learning.cfm
- 证据：
  - `Many Uses of Type` 把 cognitive processes 的应用场景直接分成 Learning / Creativity / Communication / Idea Generation / Skill Development / Problem Solving，说明本站明显偏“把功能当作认知操作系统”而不只是人格标签
  - `Communication` 页最重要的结论是：每个过程都带着不同的 conversation premises；很多误解不是立场差，而是 process voice 差
  - 同页还给了非常实用的对话建议：卡住时先调动自己的 relief role；做重要决定时要有意识地引入更多过程；想调动内倾过程就先留独处时间，想调动外倾过程就进互动
  - `Problem Solving` 页直接把压力和功能失衡联系起来：人在压力下会把偏好过程“音量开太大”，同时忽略低偏好过程，于是会越用越卡
  - 该页还给出每个过程在卡住时可能出现的失衡表现：例如 Si 可能过度类比旧经验并不信任新信息，Ne 可能被未经验证的假设吸走，Te 可能变得过度直接和快决策，Fi 可能在价值受损时固执不说或突然强硬
  - `Idea Generation` 页把创造过程拆成 diverge / converge 两步：先让 Si/Se/Ni/Ne 负责开“油门”找信息和可能性，再让 Ti/Te/Fi/Fe 负责踩“刹车”做筛选和判断
  - 该页还非常清楚地定义了 8 功能在创意会议里的贡献：
  - Se：改造眼前已有之物；找现场可用战术
  - Si：重组过去元素；从既有经验变形
  - Ne：从当前情境推出新 pattern、spinoff 和可能性
  - Ni：重写未来表征，把洞察整合成新概念
  - Te：看效率、结构、衡量标准
  - Ti：看机制、分类、是否真正讲得通
  - Fe：看合作、关系和结果是否促进和谐
  - Fi：看价值、承诺与真正重要之处是否对齐
  - `Learning` 页则强调：学习不只是学校情境，而是每天的适应与改变；8 个过程都会进入学习现场，只是切入方式不同
- 覆盖问题：A3, A4, A7, A8, A9, A11, B4, B5, B6, B7, B8, B9, B11

### 16 型页面证据

#### ISTJ

- 来源 URL：
  - https://www.cognitiveprocesses.com/16Types/ISTJ.cfm
  - https://www.cognitiveprocesses.com/16Types/16Types.cfm
- 功能栈（本站角色名）：
  - Leading: Si / Supporting: Te / Relief: Fi / Aspirational: Ne
- 证据：
  - 主题是 planning and monitoring，目标是保证质量可预测、流程有准备、资源不浪费
  - 站点把其才能写成 administrating and regulating，强调会自然看到差错、遗漏与隐患
  - B 类人设上更像“规划检视者”：可靠、务实、守标准，也会通过父母/主管/队友/志工等角色帮助他人守住秩序

#### ISFJ

- 来源 URL：
  - https://www.cognitiveprocesses.com/16types/ISFJ.cfm
  - https://www.cognitiveprocesses.com/16Types/16Types.cfm
- 功能栈（本站角色名）：
  - Leading: Si / Supporting: Fe / Relief: Ti / Aspirational: Ne
- 证据：
  - 主题是 protecting and caretaking，重点是确保自己照看的对象安全、受保护、能顺利达成目标
  - 才能被写成把事情都照料到位，好让别人成功；风格上安静、尊重、不抢戏
  - 其圆桌或群体角色更像 quietly supportive caretaker，通常不是高调带头，而是稳定提供安全垫和现实照顾
- 覆盖问题：B1, B2, B5, B8

#### INFJ

  - Leading: Ni / Supporting: Fe / Relief: Ti / Aspirational: Se
- 证据：
  - 主题是 foresight；会以一种别人还没意识到前就先“知道”的方式处理复杂议题和复杂人
  - 才能被写成 developing and guiding people，说明该站更强调 INFJ 的洞察如何落到“引导人”而非单纯抽象玄思
  - 页面把其风格写成 private and complex，但对符合愿景的项目会带着 quiet enthusiasm 和持续投入
- 覆盖问题：B1, B2, B3, B5

  - Leading: Ni / Supporting: Te / Relief: Fi / Aspirational: Se

#### ISTP

## 交叉验证提示

- 本站所有核心正文都标注为“改编自 Linda Berens / Dario Nardi 的书籍并获授权”，因此它更像一个被整理过的教学型知识站，而不是随笔型博客。后续若与 jobcannon / psychologyjunkie 这类更口语化来源冲突，应优先把它视为“理论与类型动力学定义源”。
- `Cognitive Functions` 首页用 75% / 15% 解释 dominant / auxiliary，这种比例更像教学比喻，不应机械化当成精确心理测量结论。
- 16 型页同时给出了完整 shadow stack，这与 Beebe 风格的“第五到第八功能”高度兼容；后续若与其他站只写前四功能而忽略 shadow，不算直接冲突，而是粒度不同。

## 失败/盲区记录

- 本站没有提供可直接引用的 typed dialogue / quote-style examples，因此 A10、B10 仍需其他站点补。
- 站点非常强于 A1-A9、A11 和 B1-B5、B12，但对现实社交细节、争吵场景、口头禅这类高拟真对话素材没有 jobcannon / psychologyjunkie / typemyvibe 那么直接。
- 本站虽有 16 型页面，但更偏“主题 + 过程角色 + 才能概述”，不是长篇人格散文，因此后续生成 persona 文件时仍需和更生活化来源交叉。
